Note (groupby / pandas 2.0): Pandas 2.0+ no longer silently drops columns that can’t be aggregated after a groupby, so code written for older pandas may behave differently or raise errors. In these practice materials we use .get() to select the column(s) we want after .groupby(...).mean() (or other aggregations) so that our solutions run on current pandas. On real exams you will not be penalized for omitting .get() when the old behavior would have produced the same answer.

Coleman decides that tutoring DSC 10 is not lucrative enough to support his extravagant lifestyle, so he decides to open up a sushi restaurant called Coleman’s Catch.

The DataFrame menu has a row for each menu item available at Coleman’s Catch. A few rows are shown below, but there are additional rows not shown. The "Name" of the menu item is in the index (string), and the columns are "Type" (string), "Price" in dollars (float), number of "Pieces" (int) per order, and average "Rating" from 0 to 5 (float).

Assume we have already run import babypandas as bpd and import numpy as np.

If your answer is a string, put it in quotes. If your answer is a float, include a decimal point. No calculators and no computers were allowed.

Problem 5

Lecture 5

Coleman has trouble selling certain menu items, so he creates the Coleman’s Catch of the Day Combo. All menu items with ratings below 4.5 are considered clunkers. The combo consists of the most expensive clunker of each "Type", which he sells as a bundle for $30.


Problem 5.1

Problem 5.2

Which of the following evaluates to the amount of money a customer saves by purchasing the combo versus purchasing each item individually?
