# BEGIN PROB

Select all the true statements below.

[ ] The average of the deviations from the mean is a meaningful measure of the spread of the data.
[ ] It is possible for the standard deviation of a dataset to equal zero.
[ ] It is possible for the standard deviation of a dataset to be negative.
[ ] Given the standard deviation of a dataset, we can determine its mean.
[ ] Given the standard deviation of a dataset, we can determine its variance.

# BEGIN SOLUTION
**Answer:** Option 2 and Option 5

- **Option 1 is false.** The deviations from the mean always add up to 0, because the positive deviations exactly cancel the negative ones. So their average is always 0 for every dataset and tells us nothing about spread. That's why we square the deviations before averaging.
- **Option 2 is true.** If every value in the dataset is the same, every deviation from the mean is 0, so the standard deviation is 0.
- **Option 3 is false.** The standard deviation is the square root of the variance, and the variance is an average of squared deviations, which can't be negative. The square root of a non-negative number is never negative.
- **Option 4 is false.** The standard deviation only measures how spread out the data is, not where it's centered. For example, `[1, 2, 3]` and `[101, 102, 103]` have the same standard deviation but different means.
- **Option 5 is true.** The variance is the standard deviation squared, so if we know the standard deviation, we can square it to get the variance.
