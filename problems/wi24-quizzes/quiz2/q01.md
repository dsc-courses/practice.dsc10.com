# BEGIN PROB

We'd like to visualize the distribution of the `"Mfr"` column in the
`laptops` DataFrame. Fill in the blanks so that the code below draws an
appropriate plot.

    laptops.groupby(__(a)__).__(b)__.get([__(c)__]).plot(kind=__(d)__)

# BEGIN SOLUTION

**Answer:** 

**Answer (a):** `"Mfr"`

We want to see how laptops are distributed across manufacturers, so we group by the `"Mfr"` column.

<average>92</average>

**Answer (b):** `count()`

`.count()` counts the number of rows in each group. Grouping by `"Mfr"` and then counting tells us how many laptops come from each manufacturer, which is exactly the distribution we want to plot.

<average>82</average>

**Answer (c):** `"Model"`, `"OS"`, `"Screen Size"`, or `"Price"`

After `laptops.groupby("Mfr")`, the `"Mfr"` column becomes the index rather than a regular column. So `.count()` returns a DataFrame with one row per manufacturer, where every remaining column holds the same count (the number of laptops from that manufacturer). Since all of these columns contain identical values, we can pick **any one** of them with `.get([...])` — just not `"Mfr"` itself, since it's no longer a column.

<average>56</average>

**Answer (d):** `"bar"` or `"barh"`

`"Mfr"` is a categorical variable (manufacturer names), and the standard way to visualize the distribution of a categorical variable is a bar chart, with one bar per category.

<average>68</average>
