# BEGIN PROB

Fill in the blanks so that `rotten_apple` evaluates to the number of
laptops manufactured by `"Apple"` that are priced below the median price
of all laptops.

    x = __(a)__
    y = __(b)__
    rotten_apple = laptops[x __(c)__ y].__(d)__


# BEGIN SOLUTION

Note: (a) and (b) are interchangeable

**Answer (a):** `laptops.get("Mfr") == "Apple"`

This is a Boolean Series that is `True` for rows where the manufacturer is `"Apple"` and `False` otherwise.

<average>71</average>

**Answer (b):** `laptops.get("Price") < laptops.get("Price").median()`

This is a Boolean Series that is `True` for rows priced below the median. Note the median here is computed over **all** laptops in `laptops`, not just Apple ones — `rotten_apple` should count Apple laptops priced below the overall median price, not the median of Apple laptops alone.

<average>71</average>

**Answer (c):** `&`

We want rows that satisfy **both** conditions `x` and `y` at once. Since `x` and `y` are Boolean Series (not single `True`/`False` values), we combine them element-wise with `&`, not the Python keyword `and`, which only works on single Booleans.

<average>43</average>

**Answer (d):** `shape[0]`

`laptops[x & y]` is the DataFrame of rows matching both conditions. `.shape` gives `(number of rows, number of columns)`, so `.shape[0]` pulls out the number of rows — the count of matching laptops we want.

<average>43</average>
