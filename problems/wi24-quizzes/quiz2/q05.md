**Using `groupby`**, write an expression that evaluates to the average
price of laptops with the `"macOS"` operating system.


# BEGIN SOLUTION

**Answer:** `laptops.get(["OS", "Price"]).groupby("OS").mean().get("Price").loc["macOS"]`

We first select only the `"OS"` and `"Price"` columns with `.get([...])`. This avoids errors from trying to average non-numeric columns like `"Model"`, and keeps only the column we're grouping by and the one we want to average. `.groupby("OS").mean()` then gives one row per operating system, with the average price in each column. `.get("Price")` pulls out that column as a Series indexed by `"OS"`, and `.loc["macOS"]` looks up the value for `"macOS"` specifically.

<average>72</average>

**Without using `groupby`**, write an expression that evaluates to the
average price of laptops with the `"macOS"` operating system (the same
quantity as above).


# BEGIN SOLUTION

**Answer:** `laptops[laptops.get("OS") == "macOS"].get("Price").mean()`

`laptops.get("OS") == "macOS"` is a Boolean Series that is `True` for macOS laptops. Using it to query `laptops` keeps only those rows. From there, `.get("Price")` selects the `"Price"` column, and `.mean()` computes its average — the average price of macOS laptops, without ever grouping.

<average>71</average>
