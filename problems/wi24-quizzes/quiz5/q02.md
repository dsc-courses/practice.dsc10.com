# BEGIN PROB

Bill claims that San Diego is sunny 60% of the year, but you think the
percentage is higher. You decide to test the validity of Bill's claim by
running a hypothesis test.

# BEGIN SUBPROB

Both your null and alternative hypotheses will take this form:

*The percentage of sunny days in San Diego is ______ 60%.*

\(i\) For the null hypothesis, how should we fill in the blank?

( ) equal to 
( ) not equal to 
( ) greater than 
( ) less than

\(ii\) For the alternative hypothesis, how should we fill in the blank?

( ) equal to 
( ) not equal to 
( ) greater than 
( ) less than

# BEGIN SOLUTION

**Answer (i):** equal to

The null hypothesis is Bill's claim, and it has to give an exact value we can simulate under. "The percentage of sunny days in San Diego is equal to 60%" tells us exactly what probability to use in a simulation.

<average>89</average>

**Answer (ii):** greater than

The alternative hypothesis is what you believe instead of Bill's claim. You think the percentage is higher than 60%, so the alternative hypothesis is that the percentage of sunny days is greater than 60%.

<average>75</average>

Say that in 2023, San Diego had 235 sunny days. Using the number of
sunny days per year as the test statistic, fill in the following code to

# BEGIN SOLUTION

**Answer (w):** `235`

The test statistic is the number of sunny days in a year, so the observed statistic is the number of sunny days we actually saw in 2023, which is 235.

<average>58</average>

**Answer (x):** `random.multinomial`

`np.random.multinomial(365, ...)` simulates 365 days, where each day is randomly assigned to a category based on the given probabilities. It returns an array with the number of days that landed in each category.

<average>93</average>

**Answer (y):** `[0.6, 0.4]`

We simulate under the null hypothesis, so each day has a 60% chance of being sunny and a 40% chance of not being sunny. The first category must be sunny days, because we take `[0]` from the result to get the number of sunny days in the simulated year.

<average>65</average>

**Answer (z):** `>=`

The p-value is the proportion of simulated statistics that are equal to, or at least as extreme as, the observed statistic, in the direction of the alternative hypothesis. Our alternative hypothesis is that the percentage is greater than 60%, so more sunny days counts as more extreme. We count the simulated years with at least 235 sunny days.

<average>67</average>

Suppose the p-value of this hypothesis test is 0.1. Which of the following statements is a correct interpretation of this p-value?

( ) If the null hypothesis is true, there is a 10% chance of obtaining a test statistic equal to the observed statistic.
( ) If the null hypothesis is true, there is a 90% chance of obtaining a test statistic equal to the observed statistic.
( ) If the null hypothesis is true, there is a 10% chance of obtaining a test statistic equal to, or at least as extreme as, the observed statistic.
( ) If the alternative hypothesis is true, there is a 90% chance of obtaining a test statistic equal to, or at least as extreme as, the observed statistic.

# BEGIN SOLUTION

**Answer:** If the null hypothesis is true, there is a 10% chance of obtaining a test statistic equal
to, or at least as extreme as, the observed statistic.

The p-value is calculated by simulating under the null hypothesis, so it tells us how likely our results are **if the null hypothesis is true**. That rules out the last option, which assumes the alternative hypothesis is true.

The p-value counts outcomes that are equal to **or more extreme than** the observed statistic, not just outcomes exactly equal to it. That rules out the first two options.

A p-value of 0.1 means that, if the null hypothesis is true, there is a 10% chance of getting a test statistic equal to, or at least as extreme as, the observed statistic.
