Fill in the blanks below so that `grouped` is a DataFrame showing how
many flights on each airline departed from each airport.

```py
    grouped = flights.groupby(___(x)___).___(y)___.get(["flight_num"])
```


# BEGIN SOLUTION

**Answer (x):** `["departure", "airline"]` or `["airline", "departure"] `

"How many flights on each airline departed from each airport" asks for a count for every **combination** of departure airport and airline. Grouping by a list of both columns creates one group — one row in the output — for each distinct (departure, airline) pair that appears in `flights`. The order of the two columns in the list doesn't change which pairs exist, only how the resulting index is arranged.

**Answer (y):** `count()`

`.count()` counts the number of flights that fall into each group. `.get(["flight_num"])` then keeps just the `"flight_num"` column (wrapped in a list so the result stays a DataFrame), which holds that count for every (departure, airline) pair.

# BEGIN SUBPROB

Suppose the expression `grouped.shape[0] == flights.shape[0]` evaluates
to `True`. Select all true statements below.

[ ] No two flights in `flights` were on the same airline.
[ ] No two flights in `flights` had the same departure and arrival airports.
[ ] Among all flights in `flights` that were on the same airline, no two had the same departure airport.
[ ] Among all flights in `flights` from the same departure airport, no two were on the same airline.

# BEGIN SOLUTION

**Answer:** Option 3 and Option 4

`grouped` has one row per distinct (departure, airline) pair, and `grouped.shape[0] == flights.shape[0]` means there are exactly as many such pairs as there are flights. Since no row can be grouped twice, this means **every flight has a unique (departure, airline) pair** — no two flights share both the same departure airport and the same airline.

**Option 1: False.** This would mean every flight is on a different airline, which is much stronger than what we're told. Two flights can share an airline, as long as they don't also share a departure airport.

**Option 2: False.** Arrival airport isn't one of the columns we grouped by, so this condition doesn't follow from `grouped.shape[0] == flights.shape[0]` at all.

**Option 3: True.** If two flights were on the same airline *and* had the same departure airport, they'd share the same (departure, airline) pair, which we just said can't happen. So within a single airline, every flight departs from a different airport.

**Option 4: True.** This is the same fact, viewed the other way: if two flights departed from the same airport *and* were on the same airline, they'd again share a pair. So among flights from the same airport, every flight is on a different airline.
