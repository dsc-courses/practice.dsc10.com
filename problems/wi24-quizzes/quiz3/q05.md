# BEGIN PROB

Use the function defined below to answer the questions on the right.

    def discount(duration, price):
        if duration > 6:
            price = price * 0.9
        if duration > 4:
            price = price * 0.95 
        elif duration > 3:
            price = price * 0.98
        else:
            price = price * 0.99 
        price = price - 5 
        return price

# BEGIN SUBPROB

What is the output of `discount(7, 100)`?

( ) `100 * 0.9 * 0.95 * 0.98 - 5`
( ) `100 * 0.9 * 0.95 - 5`
( ) `100 * 0.9 - 5`
( ) `100 * 0.9`

# BEGIN SOLUTION

**Answer:** Option 2

`discount` has **two separate conditional blocks**, not one long chain — the second `if`/`elif`/`else` is independent of the first `if`. Calling `discount(7, 100)` runs both blocks:

- First block: `duration > 6` is `7 > 6`, which is `True`, so `price = 100 * 0.9`.
- Second block: `duration > 4` is `7 > 4`, which is `True`, so this branch runs (and the `elif`/`else` are skipped): `price = (100 * 0.9) * 0.95`.
- Finally, `price = price - 5`.

So the output is `100 * 0.9 * 0.95 - 5`, which is Option 2.

Find `x` and `y` such that `discount(x, y)` evaluates to
`97 * 0.98 - 5`.

# BEGIN SOLUTION

**Answer (x):** anything greater than `3` and less than or equal to `4`

The target expression `97 * 0.98 - 5` only has **one** multiplier, `0.98`, before the `- 5`. That `0.98` only comes from the `elif duration > 3` branch of the second block, so the first `if duration > 6` block must **not** have multiplied `price` by anything — meaning it didn't run, so `duration` must be `6` or less. The `elif duration > 3` branch running (instead of the `if duration > 4` branch before it, or the `else`) means `duration` is greater than `3` but not greater than `4`. Together, that's `3 < duration <= 4`.

**Answer (y):** `97`
