# BEGIN PROB

Suppose we have another DataFrame `more_flights` which contains the same
columns as `flights`, but different rows. Define `merged` as follows.
```py
        merged = flights.merge(more_flights, on = "airline")
```
Suppose that in `merged`, there are 108 flights where the airline is
`"United"`, and in `more_flights`, there are 12 flights where the
airline is `"United"`. If `flights` has 15 rows in total, how many of
these rows are **not** for `"United"` flights? Give your answer as an
integer.


# BEGIN SOLUTION

**Answer:** 6

When we merge on `"airline"`, every `"United"` row in `flights` is paired with every `"United"` row in `more_flights`. So the number of `"United"` rows in `merged` is

$$(\text{\# United rows in } \texttt{flights}) \times (\text{\# United rows in } \texttt{more\_flights}).$$

We're told this product is $108$, and that `more_flights` has $12$ `"United"` rows, so

$$(\text{\# United rows in } \texttt{flights}) \times 12 = 108 \implies \text{\# United rows in } \texttt{flights} = 9.$$

Since `flights` has $15$ rows in total, the number that are **not** `"United"` flights is

$$15 - 9 = \boxed{6}.$$
