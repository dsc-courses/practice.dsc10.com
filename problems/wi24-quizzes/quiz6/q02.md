between the number of B spaces and the total number of parking spaces in
each region of campus. Note that these numbers represent a **count of

# BEGIN SUBPROB

Based on these scatter plots, which pair of variables has a larger
correlation coefficient?

( ) A Spaces and Total Spaces 
( ) B Spaces and Total Spaces

# BEGIN SOLUTION

**Answer:** B Spaces and Total Spaces

The correlation coefficient measures how closely the points follow a straight line. Both plots show a positive association, but the points in the B plot sit much closer to the regression line.

In plot A, many points are far from the line. That scatter around the line means a weaker linear relationship, so a smaller correlation coefficient.

A common mistake is to compare the slopes of the two lines. The correlation coefficient doesn't depend on how steep the line is. It only measures how tightly the points cluster around it.

# BEGIN SUBPROB

Which of the following variables would most likely be negatively
associated with the total number of spaces in a campus region?

( ) Total area of the campus region
( ) Number of athletic fields in the campus region
( ) Number of residents in the campus region
( ) Number of electric vehicle charging stations in the campus region

# BEGIN SOLUTION

**Answer:** Number of athletic fields in the campus region

Two variables are negatively associated if as one variable increases, the other tends to decrease. Athletic fields take up land that could otherwise be used for parking, so regions with more athletic fields would likely have fewer parking spaces.

**Total area of the campus region.** Positive association. A bigger region has more room for parking.

**Number of residents in the campus region.** Positive association. More residents means more people who need somewhere to park.

**Number of electric vehicle charging stations in the campus region.** Positive association. Charging stations are built into parking spaces, so regions with more parking tend to have more of them.

# BEGIN SUBPROB

The number of S spaces and the total number of parking spaces in each
campus region are linearly related with a correlation coefficient of
0.6. The number of S spaces in the Warren College region of campus is 5
standard deviations below average. What does the regression line predict
for the number of total spaces in Warren College, measured in standard
units?

# BEGIN SOLUTION

**Answer:** -3

When both variables are measured in standard units, the regression line is

$$\text{predicted } y_{\text{(su)}} = r \cdot x_{\text{(su)}}$$

Warren College's number of S spaces is 5 standard deviations below average, so $x_{\text{(su)}} = -5$. With $r = 0.6$:

$$\text{predicted } y_{\text{(su)}} = 0.6 \cdot (-5) = -3$$

So the regression line predicts that Warren College's total number of spaces is 3 standard deviations below average.

Common mistakes:

- **Answering -5.** That assumes a perfect correlation ($r = 1$). Because $r = 0.6$, the prediction is pulled closer to the average. This is called regression to the mean.
- **Answering 5 or 3.** "Below average" means a negative value in standard units.

# BEGIN SUBPROB

True or False: Since number of parking spaces is always a positive
integer, the regression line that predicts the total number of spaces
from the number of S spaces must have a positive $y$-intercept.

( ) True 
( ) False

# BEGIN SOLUTION

**Answer:** False

The $y$-intercept is the line's prediction when the number of S spaces is 0. The regression line is chosen to fit the data as well as possible, not to give realistic numbers of parking spaces, so its predictions can be negative. Its predictions are most accurate within the range of the data. So if no region has close to 0 S spaces, the $y$-intercept may not be a realistic value at all.

A common mistake is to treat the regression line as if it had to follow the rules of the data. Its predictions don't have to be positive or whole numbers.
