# BEGIN PROB

The Best Pizza Neighborhood Contest is coming up! For this contest, we want to find the neighborhood with the highest average rating for a slice of pizza. Fill in the blanks below so that the expression evaluates to the **name** of this neighborhood (as a string).

    pizza.get([___(a)___]).groupby(___(b)___)
                          .___(c)___.sort_values(__(d)__, ascending=False)
                          ._____(e)_____

# BEGIN SUBPROB

**(a)**

# BEGIN SOLUTION

**Answer:** `"rating", "neighborhood"`

We only need two columns: `"rating"`, which is what we're averaging, and `"neighborhood"`, which is what we're grouping by. Keeping just these two also drops the other string columns, like `"store"` and `"kind"`, which can't be averaged by `.mean()` in part (c). The order of the two column names doesn't matter.

<average>76</average>

# END SOLUTION

# END SUBPROB

# BEGIN SUBPROB

**(b)**

# BEGIN SOLUTION

**Answer:** `"neighborhood"`

We want one average rating **per neighborhood**, so we group by `"neighborhood"`. After grouping, each neighborhood name becomes a label in the index of the result.

<average>84</average>

# END SOLUTION

# END SUBPROB

# BEGIN SUBPROB

**(c)**

# BEGIN SOLUTION

**Answer:** `mean()`

`.mean()` combines all the rows in each group into one row by averaging the `"rating"` column. The result has one row per neighborhood, holding that neighborhood's average rating.

<average>85</average>

# END SOLUTION

# END SUBPROB

# BEGIN SUBPROB

**(d)**

# BEGIN SOLUTION

**Answer:** `by="rating"`

We want the neighborhood with the highest average rating, so we sort by the `"rating"` column, which now holds the averages. With `ascending=False`, the highest average comes first.

<average>88</average>

# END SOLUTION

# END SUBPROB

# BEGIN SUBPROB

**(e)**

# BEGIN SOLUTION

**Answer:** `index[0]`

**Explanation (full pipeline):**

1. `.get(["rating", "neighborhood"])` — keep both columns: `"rating"` to average and `"neighborhood"` to group by.
2. `.groupby("neighborhood")` — one group per neighborhood.
3. `.mean()` — average `"rating"` within each neighborhood (one row per neighborhood).
4. `.sort_values(by="rating", ascending=False)` — sort by average rating, highest first.
5. `.index[0]` — after sorting, the first row’s index label is the name of the neighborhood with the highest average rating (a string).

<average>53</average>

# END SOLUTION
