# BEGIN PROB

Punch is a baby Japanese macaque; zookeepers recorded his last **50** interactions (**20** friendly). For a typical macaque, **50%** of interactions are friendly. Minchan tests whether Punch is treated **worse** (fewer friendly) using:

- **Null:** \(P(\text{friendly}) = 0.5\) for each interaction.
- **Alternative:** \(P(\text{friendly}) < 0.5\).

Assume `total_variation_distance(dist1, dist2)` computes TVD as in class. Code skeleton:

```py
A. expected = 50 * 0.5
B. obs = abs(20 - expected)
C. stats = np.array([])
D. for i in np.arange(1000):
E.     n = np.random.multinomial(50, [0.5, 0.5])[0]
F.     stat = abs(n - expected)
G.     stats = np.append(stats, stat)
H. p_value = np.count_nonzero(stats >= obs) / 1000
```

# BEGIN SUBPROB

**(a)** If Minchan runs the code **unchanged**, **select all** true statements.

[ ] A histogram of `stats` would be centered at 0.
[ ] A histogram of `stats` would have a peak at 5.
[ ] `p_value` is approximately **twice** what it should be for the stated one-sided alternative.
[ ] `p_value` is **more than** twice what it should be.
[ ] None of the above

# BEGIN SOLUTION

**Answer:** Only the **third** statement — using `abs` makes the test effectively two-sided, roughly doubling the one-sided \(p\)-value.

Explanation:

Step 1: Under the null hypothesis, Punch has a $50%$ chance of receiving a friendly interaction. Since the zookeepers recorded $50$ interactions, the expected number of friendly interactions is $50 * 0.5 = 25$. However, Punch received only $20$ friendly interactions.

Step 2: The original code calculates the observed statistic using `abs(20 - expected)`, which gives `abs(20 - 25) = 5`. Similarly, the simulated statistic is calculated using `abs(n - expected)`. Taking the absolute value removes the direction of the difference. For example, both $20$ and $30$ friendly interactions would produce a statistic of $5$.

Step 3: The alternative hypothesis states that Punch receives fewer friendly interactions than expected, so we should only consider unusually low counts. However, the original code counts deviations in both directions because of `abs()`. Since the null distribution is symmetric around $25$, this produces a simulated p-value approximately twice as large as the correct one-sided p-value.

Step 4: The first statement is incorrect because the simulated statistics cannot be negative, so their distribution is not symmetric around $0$. The second statement is incorrect because the statistics tend to be concentrated near $0$ rather than having a peak at $5$.

Therefore, only the third statement is correct.

**Answer:** `np.count_nonzero(stats <= obs) / 1000` — one-sided alternative “less than 0.5” means more extreme = smaller or equal `stat`; divide by number of simulations.

Explanation:

Step 1: The p-value represents the probability of obtaining a test statistic at least as extreme as the observed statistic, assuming the null hypothesis is true. Since the alternative hypothesis states that Punch receives fewer friendly interactions, we are interested in unusually small values of the test statistic.

Step 2: We use `stats <= obs` to identify simulated statistics that are less than or equal to the observed statistic. For example, since `obs = -5`, we count simulated statistics that are $-5$ or smaller.

Step 3: We apply `np.count_nonzero(stats <= obs)` to count how many simulated statistics satisfy this condition.

Step 4: Finally, we divide by $1000$ because the simulation was repeated $1,000$ times. This gives the proportion of simulated statistics that are at least as extreme as the observed statistic in the direction of the alternative hypothesis.

We do not use `stats >= obs` because that would count values in the opposite direction. We also do not divide by $50$ because $50$ represents the number of interactions in each simulation, not the number of repetitions.
