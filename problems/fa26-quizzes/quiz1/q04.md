# BEGIN PROB

Ray, founder of Ray's Reviews, writes that the sushi from Coleman's Catch is delicious, but it may be overpriced. Fill in the blanks below to create a DataFrame called `money`, which is indexed by `"Type"` and has just one column, `"price_per_piece"`, that contains the highest price per individual piece of a menu item in each of the different `"Type"` categories.

```py
unit_price = menu.assign(price_per_piece = __(A)__)
money = unit_price.get(__(B)__).groupby("Type").__(C)__
```

# BEGIN SUBPROB

What goes in blank (A)?

# BEGIN SOLUTION

**Answer:** `menu.get("Price") / menu.get("Pieces")`

Price per piece is the order’s price divided by the number of pieces in it. Dividing one Series by another works element-wise, so each row’s price gets divided by that row’s number of pieces. assign then stores the result as the new column "price_per_piece".

# END SOLUTION

# BEGIN SUBPROB

What goes in blank (B)?

# BEGIN SOLUTION

**Answer:** `["Type", "price_per_piece"]`

We need to keep only the two columns that matter. "Type" has to be included because .groupby("Type") needs it as a column to group by. "price_per_piece" is the one value we want in the result. Passing a list to .get returns a DataFrame, which is what .groupby needs. If we left out this step, the aggregation in blank (C) would also run on "Price", "Pieces", and "Rating", and money would have more than one column.

# END SOLUTION

What goes in blank (C)?

# BEGIN SOLUTION

**Answer:** `max()`

After grouping by "Type", .max() finds the largest "price_per_piece" within each type. The result is indexed by "Type" with a single column "price_per_piece", which matches what the problem describes.
