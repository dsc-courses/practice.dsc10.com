# BEGIN PROB

Coleman has trouble selling certain menu items, so he creates the *Coleman's Catch of the Day Combo*. All menu items with ratings below 4.5 are considered clunkers. The combo consists of the most expensive clunker of each `"Type"`, which he sells as a bundle for $30.

# BEGIN SUBPROB

Fill in the blank so that `clunkers` is a DataFrame consisting of the rows of `menu` with ratings below 4.5.

```py
clunkers = ____
```

# BEGIN SOLUTION

**Answer:** `menu[menu.get("Rating") < 4.5]`

menu.get("Rating") < 4.5 is a Boolean Series that’s True for each row with a rating below 4.5. Putting it in square brackets after menu queries for only the True rows. The condition is strictly below 4.5, so use <, not <=.

# BEGIN SUBPROB

Which of the following evaluates to the amount of money a customer saves by purchasing the combo versus purchasing each item individually?

( ) `clunkers.groupby("Type").sum().get("Price").max() - 30`
( ) `30 - clunkers.groupby("Type").sum().get("Price").max()`
( ) `clunkers.groupby("Type").max().get("Price").sum() - 30`
( ) `30 - clunkers.groupby("Type").max().get("Price").sum()`

# BEGIN SOLUTION

**Answer:** Option 3.

The combo has the most expensive clunker of each type, and we want what the customer saves compared to buying those items separately.

clunkers.groupby("Type").max().get("Price") gives the highest clunker price in each type.

.sum() adds those up, which is what buying all the combo items individually would cost.

Subtracting the $30 combo price gives the savings.

Option 1 is wrong because sum() adds up all the clunkers in each type, not just the most expensive one. Then .max() picks only one type’s total. This isn’t the cost of the combo items.

Option 2 is wrong because it has the same wrong cost as option 1, and the subtraction is also flipped.

Option 4 is wrong because the cost is right, but 30 - cost is negative whenever the combo is a good deal. Savings should be the cost minus $30.
