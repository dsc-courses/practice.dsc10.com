# BEGIN PROB

Coleman purchased a property on Clougherty Drive, but the street number can only be determined by evaluating the following expression. What is the street number?

```py
sum(2 ** np.arange(3, 7, 2)) * len(str(len("sushi" * 999)))
```

# BEGIN SOLUTION

**Answer:** `160`

The np.arange(3, 7, 2) results in an array that starts at 3, steps by 2, and stops before 7, which produces [3, 5].

2 ** np.array([3, 5]) raises 2 to each element, giving [8, 32], and sum of that is 40.

On the other side of the expression, "sushi" * 999 repeats the 5-character string 999 times, so len(...) is just 5 * 999, which equals 4995.

str() wraps around 4995, producing "4995", and its len is 4.

Finally, we have 40 * 4, which produces an answer of 160.
