Suppose we have access to a simple random sample of all US Costco
members of size **145**. Our sample is stored in a DataFrame named
`us_sample`, in which the `"Spend"` column contains the October 2023
spending of each sampled member in dollars.

# BEGIN SUBPROB

"The average of the <code>"Spend"</code> column in <code>us_sample</code> is a ____,
while the average October 2023 spending of all US members is a ____."
</center>

<br>

( ) sample statistic; population parameter
( ) population statistic; sample parameter
( ) sample parameter; population statistic
( ) population parameter; sample statistic

# BEGIN SOLUTION

**Answer**: sample statistic; population parameter

A number computed from a **sample** (the average of the `"Spend"` column in `us_sample`) is a **statistic**. A number that describes the entire **population** (the average spending of all US members) is a **parameter**.

# BEGIN SUBPROB

Fill in the blanks below so that `us_left` and `us_right` are the left
and right endpoints of a **46%** confidence interval for the average
October 2023 spending of all US members.

```py
costco_means = np.array([])
for i in np.arange(5000):
    resampled_spends = __(x)__
    costco_means = np.append(costco_means, resampled_spends.mean())
left = np.percentile(costco_means, __(y)__)
right = np.percentile(costco_means, __(z)__)
```

Which of the following could go in blank (x)? **Select all that apply.**

[ ] `us_sample.sample(145, replace=True).get("Spend")`
[ ] `us_sample.sample(145, replace=False).get("Spend")`
[ ] `np.random.choice(us_sample.get("Spend"), 145)`
[ ] `np.random.choice(us_sample.get("Spend"), 145, replace=True)`
[ ] `np.random.choice(us_sample.get("Spend"), 145, replace=False)`
[ ] None of the above.

What goes in blanks (y) and (z)? Give your answers as integers.

# BEGIN SOLUTION

**Answer**: 

- `x`: 
    - `us_sample.sample(145, replace=True).get("Spend")`
    - `np.random.choice(us_sample.get("Spend"), 145)`
    - `np.random.choice(us_sample.get("Spend"), 145, replace=True)`
- `y`: `27`
- `z`: `73`

To bootstrap, we **resample from our original sample, with replacement, using the same size as the original sample** (145).

- `us_sample.sample(145, replace=True).get("Spend")` is correct.
- `us_sample.sample(145, replace=False).get("Spend")` is incorrect. Sampling 145 rows without replacement from 145 rows just reshuffles the sample, so every resample has the same mean.
- `np.random.choice(us_sample.get("Spend"), 145)` is correct, since `np.random.choice` samples **with** replacement by default.
- `np.random.choice(us_sample.get("Spend"), 145, replace=True)` is correct.
- `np.random.choice(us_sample.get("Spend"), 145, replace=False)` is incorrect, for the same reason as the second option.

For a 46% confidence interval, we want the middle 46% of the bootstrapped means. That leaves $100\% - 46\% = 54\%$ in the tails, or 27% in each tail. So the left endpoint is the 27th percentile and the right endpoint is the $100 - 27 = 73$rd percentile.

<average>79</average>

True or False: If we repeat the code from part (b) 200 times, each time
bootstrapping from a new random sample of 145 members drawn from all US
members, then about **92** of the intervals we create will contain the
average October 2023 spending of all US members.

( ) True 
( ) False

# BEGIN SOLUTION

**Answer**: True

This is the correct interpretation of a confidence interval. If we repeatedly draw a new random sample from the population, bootstrap from it, and build an interval, about 46% of those intervals will contain the population mean. Since $0.46 \times 200 = 92$, about 92 of the 200 intervals will contain the average spending of all US members.

# BEGIN SOLUTION

**Answer**: False

The difference from the previous part is that here we bootstrap from the **same** `us_sample` every time. Each interval is built from the same sample, so all 200 intervals will be nearly identical (centered around the same sample mean). Either almost all of them will contain the population mean or almost none will, depending on whether this one sample happened to be representative. The "about 46%" interpretation only works when each interval comes from a **new** random sample from the population.
