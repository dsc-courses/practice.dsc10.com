# BEGIN PROB

Consider the following assignment statement.

```py
puffin = np.array([5, 9, 13, 17, 21])
```

# BEGIN SUBPROB

Provide arguments to call `np.arange` with so that the array `penguin`
is identical to the array `puffin`.

```py
penguin = np.arange(____)
```

# BEGIN SOLUTION

**Answer**: We need to provide `np.arange` with three arguments: 5, anything in $(21, 25]$, 4. For instance, something like `penguin = np.arange(5, 25, 4)` would work.

`np.arange(start, stop, step)` starts at `start` and keeps adding `step`, stopping before it reaches `stop`. The array `puffin` starts at 5 and goes up by 4 each time, so `start` is 5 and `step` is 4.

The stop value is never included, so it must be greater than 21, or 21 would be left out. It also can't be greater than 25, because then the next value, 25, would be included. So any stop value in $(21, 25]$ works. For example, `np.arange(5, 22, 4)` and `np.arange(5, 25, 4)` both give `array([5, 9, 13, 17, 21])`.

# BEGIN SOLUTION

**Answer**:

- `x`: `2`
- `y`: anything in $(8, 10]$
- `z`: `5`

Let's work from the inside out. First inside the arange, we need length 5 so anywhere between 8-10 results in 5 entries in the array. Next, we need to multiply by 2 since the difference between elements in the final array should be 4, while the arange difference is 2. Finally, add 5 to make the first element from 0 to 5, and the other elements follow suit.
