# BEGIN PROB

The DataFrame `keepers` has 5 rows, each of which represents a different
shopkeeper in the *Animal Crossing: New Horizons* universe.

`keepers` is shown below in its entirety.

<center><img src="../../assets/images/fa23-quizzes/keepers1.png" width=200></center>

<br>

How many rows are in the following DataFrame? Give your answer as an
integer.

```py
keepers.merge(items.take(np.arange(6)), 
              left_on="Store", 
              right_on="Location")
```

# BEGIN SOLUTION

**Answer**: 10

This code merges `keepers` (left) with `items.take(np.arange(6))` (right), which is the first 6 rows of `items`. A row from `keepers` and a row from `items` are combined whenever the `"Store"` value in `keepers` is the same as the `"Location"` value in `items`.

`keepers` has:

- 1 row of "Able Sisters Shop"
- 3 rows of "Nook's Cranny"
- 1 row of "Kicks Shoe Store"

The first 6 rows of `items` have:

- 1 row of "Able Sisters Shop"
- 3 rows of "Nook's Cranny"
- 1 row of "Crafting"
- 1 row of "Birthday Gift"

For each value that appears in both DataFrames, we multiply the number of matching rows in each, then add up the products:

- "Able Sisters Shop": $1 \times 1 = 1$ row
- "Nook's Cranny": $3 \times 3 = 9$ rows

"Kicks Shoe Store", "Crafting" and "Birthday Gift" each appear in only one DataFrame, so they produce no rows.

$$1 + 9 = \boxed{10} \text{ rows}$$
