# BEGIN PROB

Fill in the blanks so that `count_1` and `count_2` both evaluate to the
number of items in `items` with a `"Cost"` of 0.

```py
count_1 = items.groupby(__(a)__).__(b)__().get("Item").loc[__(c)__]
count_2 = items[__(d)__].shape[0]
```

# BEGIN SOLUTION

**Answer**:

- `a`: `"Cost"`
- `b`: `count`
- `c`: `0`
- `d`: `items.get("Cost") == 0`

**count_1:**

`items.groupby("Cost").count()` creates one row per distinct cost, with the cost as the index. Each remaining column holds the number of items at that cost. We select the "Item" column with `.get("Item")`, and `.loc[0]` pulls out the entry whose index label is 0, which is the number of items costing 0 bells.

**count_2:**

We query the `items` DataFrame with the Boolean Series `items.get("Cost") == 0`, to keep only the rows with a "Cost" of 0 bells. Then, we do `.shape[0]` to count the number of rows.
