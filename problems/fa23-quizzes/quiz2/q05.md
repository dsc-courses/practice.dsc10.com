# BEGIN PROB

Consider the function `tom_nook`, defined below. Recall that if `x` is
an integer, `x % 2` is `0` if `x` is even and `1` if `x` is odd.

```py
def tom_nook(crossing):
    bells = 0
    for nook in np.arange(crossing):
        if nook % 2 == 0:
            bells = bells + 1
        else:
            bells = bells - 2
    return bells
```

What value does `tom_nook(8)` evaluate to?

( ) -6
( ) -4
( ) -2
( ) 0
( ) 2
( ) 4
( ) 6

# BEGIN SOLUTION

**Answer**: -4

Calling `tom_nook(8)` passes `8` into `crossing`, so the loop runs over `np.arange(8)`, which is $0, 1, 2, 3, 4, 5, 6,$ and $7$. We initialize the variable `bells` as $0$.

`nook % 2` is the remainder when `nook` is divided by $2$, so it equals $0$ for even numbers and $1$ for odd numbers. That means:

**If `nook` is even**, `bells` goes up by $1$.
There are $4$ evens ($0, 2, 4,$ and $6$), for a total of $+4$.

**If `nook` is odd**, `bells` goes down by $2$.
There are $4$ odds ($1, 3, 5,$ and $7$), for a total of $4 \times (-2) = -8$.

$$0 + 4 - 8 = -4$$

Therefore, when we `return bells` at the end of the function, it outputs a value of $\boxed{-4}$.
