# BEGIN SUBPROB

Ella is curious if bands with more members tend to make more albums. Write one line of code to add a new column to `bands` called `"albums_per_member"`, containing the ratio of albums to members for each band.

# BEGIN SOLUTION

**Answer:**

```py
bands = bands.assign(albums_per_member = bands.get("albums") / bands.get("members"))
```

**Solution:**

`bands.get("albums") / bands.get("members")` performs elementwise division, so each band's album count is divided by its own member count, such as 12 albums and 4 members giving $\frac{12}{4}=3$. The `.assign(albums_per_member = ...)` method adds these values as a new column, and because it returns a new DataFrame rather than modifying `bands` in place, we assign the result back to `bands`.

```py
bands = bands.assign(albums_per_member = bands.get("albums") / bands.get("members"))
```

# BEGIN SUBPROB

Find the year in which the band with the highest `"albums_per_member"` ratio was formed. **Select all** options that correctly evaluate to this year (or any such year in the case of a tie).

[ ] `bands.groupby("albums_per_member").min().sort_values(by=index, ascending=True).iloc[-1]`
[ ] `bands.groupby("albums_per_member").min().reset_index().sort_values(by="albums_per_member", ascending=False).get("formed").iloc[0]`
[ ] `bands.groupby("formed").max().sort_values(by="albums_per_member", ascending=False).get("formed").iloc[0]`
[ ] `bands.groupby("formed").max().sort_values(by="albums_per_member", ascending=False).index[0]`
[ ] `bands.sort_values(by="albums_per_member", ascending=True).get("formed").iloc[-1]`
[ ] `bands.sort_values(by="formed", ascending=False).groupby("albums_per_member").max().index[0]`
[ ] None of the above.

# BEGIN SOLUTION

**Answer:**

Option 2, Option 4, and Option 5

**Solution:**

**Option 1** is incorrect because `index` is not in quotation marks, so `sort_values(by=index, ...)` raises an error, and `.iloc[-1]` would return a whole row rather than a year.

**Option 2** is correct because grouping by `"albums_per_member"`, resetting the index, sorting in descending order, and taking `.get("formed").iloc[0]` returns a formation year for a band with the highest ratio.

**Option 3** is incorrect because `groupby("formed")` makes the years the index, so `.get("formed")` fails since `"formed"` is no longer a column.

**Option 4** is correct because after `groupby("formed").max()` and a descending sort, the year with the highest ratio comes first, and `.index[0]` retrieves it from the index.

**Option 5** is correct because an ascending sort puts the highest ratio in the last row, so `.get("formed").iloc[-1]` gives its year.

**Option 6** is incorrect because grouping by `"albums_per_member"` makes the ratios the index, so `.index[0]` returns a ratio rather than a year.
