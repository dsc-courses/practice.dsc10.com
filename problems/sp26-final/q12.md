If a band has released a large number of studio albums, is their best-selling album more likely to be successful? To answer this question, you decide to use linear regression. Suppose:

- `"albums"` has mean $7$ and standard deviation $2$,
- `"top_album_sales"` has mean $21$ and standard deviation $S$, and
- the correlation coefficient between `"albums"` and `"top_album_sales"` is $0.6$.

# BEGIN SUBPROB

The band *Coldplay* has released 10 albums. How many standard deviations above the mean is *Coldplay*'s **predicted** top album sale, using our regression line? Give your answer as an **exact decimal or simplified fraction**.

::: center
:::

# BEGIN SOLUTION

**Answer:**

0.9

**Solution:**

Coldplay's album count is $\frac{10-7}{2}=1.5$ standard deviations above the mean. In standard units, the regression line predicts $y_{\text{su}}=r\cdot x_{\text{su}}$, where $r=0.6$. Therefore, Coldplay's predicted top album sale is $0.6(1.5)=\boxed{0.9}$ standard deviations above the mean.

# END SOLUTION

# BEGIN SUBPROB

If a band has $0$ albums, its top album sale should *also* be $0$. Suppose our regression line predicts that a band with $0$ albums will have a top album sale of exactly $0$. What is the standard deviation $S$ of `"top_album_sales"`? Give your answer as an **exact decimal or simplified fraction**.

::: center
:::

# BEGIN SOLUTION

**Answer:**

10

**Solution:**

The regression line has slope $r\frac{\text{SD of }y}{\text{SD of }x}=0.6\frac{S}{2}=0.3S$ and passes through the point of averages $(7,21)$. Since the line also passes through $(0,0)$, its slope must be $\frac{21-0}{7-0}=3$. Setting $0.3S=3$ gives $\boxed{S=10}$.

# END SOLUTION

Imagine for this question only that we've just discovered a mistake in our data: each studio album also has a companion live album, so the true album count for each band is **double** what's recorded. To address this, you multiply all values in the `"albums"` column by 2 and re-fit the regression line predicting `"top_album_sales"` from the new (doubled) `"albums"` variable. Which of the following statements about the **new** regression line are true? **Select all** that apply.

[ ] The new slope will be exactly double the old slope.
[ ] The new slope will be exactly half the old slope.
[ ] The new intercept will be less than the old intercept.
[ ] The new intercept will be greater than the old intercept.
[ ] The correlation coefficient $r$ will stay the same.
[ ] The RMSE of the new line is the same as the RMSE of the original line.
[ ] The predicted value for a band with a new (after doubling) album count of 30 equals **twice** the original line's prediction for a band with 15 albums.

[ ] None of the above.

# BEGIN SOLUTION

**Answer:**

Options 2, 5, and 6

**Solution:**

**Option 2** is correct because doubling every $x$-value doubles its standard deviation, so the regression slope $r\frac{\text{SD of }y}{\text{SD of }x}$ is halved, making Option 1 incorrect. **Options 3 and 4** are incorrect because the new regression line has the same intercept as the original line: doubling the mean of $x$ while halving the slope leaves the intercept unchanged. **Option 5** is correct because multiplying a variable by a positive constant does not change its correlation with another variable. **Option 6** is correct because the fitted predictions and residuals remain unchanged, so the RMSE also stays the same. **Option 7** is incorrect because the new prediction at 30 albums equals the original prediction at 15 albums, not twice that prediction, and **Option 8** is incorrect because several statements are true.

# END SOLUTION

# BEGIN SUBPROB

The DSC 10 tutors split in half and form two bands, *The Null Hypotheticals* and *P-Value and the Rejects*. They track the number of albums each band produces, as well as the sales of each band's top albums, storing this information in a two-row DataFrame called `tutors`. Instead of using the data in `bands`, they create a regression line predicting top album sales from the number of albums using **only** the data in `tutors`.

1. **True or False:** The regression line formed using the data in `bands` **cannot** have the same RMSE as the regression line formed using only the bands in `tutors`.

    ( ) True
    ( ) False

2. **True or False:** If both the `tutors` and `bands` regression lines are exactly the same line, then the `bands` DataFrame **must** include bands with the same number of albums and top album sales as the two bands in the `tutors` DataFrame.

    ( ) True
    ( ) False

# BEGIN SOLUTION

**Answer:**

- **1:** True
- **2:** False

**Solution:**

**1.** Assuming the two tutor bands have different album counts, the regression line through their two data points fits both observations perfectly, giving an RMSE of 0. The regression line for `bands` has correlation $r=0.6$, so it does not fit all observations perfectly and must have a positive RMSE. Therefore, the two regression lines cannot have the same RMSE.

**2.** Two different datasets can produce exactly the same regression line without sharing any data points. The regression line depends on the datasets' means, standard deviations, and correlation, rather than requiring particular observations to appear in both datasets. Therefore, `bands` does not need to contain either of the tutor bands' exact data points.

# END SOLUTION
