# BEGIN PROB

\[(8 pts)\]

Ray recently got into K-Pop and he wants to estimate the median number of albums among all K-Pop bands. Consider what would happen if he could somehow **repeat the following process 500 times**:

1. Take a simple random sample of K-Pop bands from the population.

2. Bootstrap resample from that sample 10,000 times, computing the median number of albums each time.

3. Construct an 80% confidence interval from the bootstrapped medians.

# BEGIN SUBPROB

**How many** of Ray's confidence intervals would we expect to contain the true median number of albums among all K-Pop bands? Give your answer as an **integer**.

::: center
:::

# BEGIN SOLUTION

**Answer:**

400

**Solution:**

An 80% confidence interval procedure is expected to capture the true population parameter approximately 80% of the time when repeated with new random samples. Since Ray repeats the entire process 500 times, the expected number of intervals containing the true median is $0.80 \times 500 = \boxed{400}$.

# END SOLUTION

# BEGIN SUBPROB

Which of the following is the most significant barrier to Ray actually completing this procedure?

( ) The computation time required to bootstrap so many times.
( ) The fact that his parameter of interest is a median and not a mean so the CLT does not apply.
( ) The logistics of obtaining new random samples from the population.
( ) The fact that he wants an 80% confidence interval instead of a standard 95% confidence interval which is easier to compute.

# BEGIN SOLUTION

**Answer:**

Option 3

**Solution:**

The biggest challenge is obtaining **500 independent random samples** of K-Pop bands from the population, which would require substantial time and resources. Option 1 is incorrect because performing bootstrap resampling computationally is generally much easier than collecting new samples. Option 2 is incorrect because bootstrapping can be used to construct confidence intervals for medians, even though the introductory CLT-based method focuses on means. Option 4 is incorrect because constructing an 80% confidence interval is no more difficult than constructing a 95% confidence interval; we simply use different percentile cutoffs.
