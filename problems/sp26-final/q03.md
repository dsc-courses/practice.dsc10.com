# BEGIN SUBPROB

Show the relationship between each band's formation year and `"top_album_sales"` to see if older bands tend to have higher sales.

( ) Scatter plot
( ) Line plot
( ) Bar chart

# BEGIN SOLUTION

**Answer:**

Scatter plot

**Solution:**

A **scatter plot** is the most appropriate choice because both the formation year and `"top_album_sales"` are numerical variables, and each point represents one band. It lets us check for an association between the two, such as a downward trend if earlier bands tend to have higher sales.

A **line plot** is less appropriate because we are comparing individual bands rather than tracking a single quantity over time, and connecting the points would imply a sequence that doesn't exist.

A **bar chart** is less appropriate because bar charts compare numerical values across categories, whereas both variables here are numerical.

( ) Scatter plot
( ) Line plot
( ) Bar chart

# BEGIN SOLUTION

**Answer:**

Line plot

**Solution:**

A **line plot** is the most appropriate choice because we want to see how a numerical quantity changes over time. We would group bands by formation year, compute the average number of members for each year, and plot formation year on the x-axis against that average on the y-axis, with the connecting line making trends in band size easy to spot.

A **scatter plot** would be better for examining the relationship between formation year and member count across individual bands, rather than a yearly summary.

A **bar chart** could display the yearly averages, but it is less effective at emphasizing the overall trend across a sequence of years.

Scatter plot
