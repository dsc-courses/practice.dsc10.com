Sofia is doing research on bands in the UK. She writes the code below to estimate the mean number of members in UK bands using a bootstrapped 85% confidence interval. Fill in the blanks to complete the code.

```py
uk = bands[bands.get("origin") == "UK"]
means = np.array([])

for i in np.arange(5000):
    resample = uk.sample(__(a)__, replace=True)
    means = np.append(means, resample.get("members").mean())

ci_low = np.percentile(means, __(b)__)
ci_high = np.percentile(means, __(c)__)
```

# BEGIN SOLUTION

**Answer:**

- **(a):** `uk.shape[0]`
- **(b):** `7.5`
- **(c):** `92.5`

**Solution:**

Each bootstrap resample must contain the same number of rows as the original DataFrame `uk`, so we use `uk.shape[0]`. For an 85% confidence interval, we want the middle 85% of the bootstrap means, leaving 15% outside the interval. Splitting this equally between the two tails gives 7.5% in each tail. Therefore, we use the **7.5th percentile** for the lower endpoint and the **92.5th percentile** for the upper endpoint.

Sofia decides to generalize her code in a function called `bootstrap_ci(df, confidence)` which takes as input the queried DataFrame and the confidence level, and returns a two-element list with the endpoints of the resulting confidence interval for the mean number of band members. uk = bands[bands.get("origin") == "UK"]

uk_width = uk_90[1] - uk_90[0]

# BEGIN SOLUTION

**Answer:**

- **1:** Option 3
- **2:** Option 4

**Solution:**

**1.** Adding Swedish bands increases the sample size, which tends to make a confidence interval narrower. Since the combined dataset also has a smaller standard deviation, both factors favor a narrower interval for `uk_sweden`. Therefore, we expect `uk_width > uk_sweden_width`.

**2.** Adding Swedish bands increases the sample size, which tends to narrow the confidence interval, but it also increases the standard deviation, which tends to widen the interval. Since these effects work in opposite directions, we cannot determine which confidence interval will be wider without additional information.

# BEGIN SUBPROB

Suppose `uk_90` comes out to be $[3.8,\ 5.2]$. Sofia's friend Elise says:

*"There is a 90% probability that the true mean number of members in UK bands is between 3.8 and 5.2."*

Which of the following is the most accurate criticism of Elise's statement?

( ) The statement should refer to individual bands, not the mean of all UK bands.
( ) The statement should say 95%, not 90%.
( ) The true mean is a fixed number and the confidence interval is also fixed, so the true mean either is or isn't in the interval $[3.8, 5.2]$.
( ) The interval is too wide to be useful. We need to lower the confidence level to get a more precise interval.

# BEGIN SOLUTION

**Answer:**

Option 3

**Solution:**

The true population mean is a fixed, unknown value rather than a random variable. Once we calculate the confidence interval $[3.8, 5.2]$, its endpoints are also fixed, so the true mean either lies inside the interval or does not. The **90% confidence level** describes the long-run success rate of the confidence interval procedure: if we repeatedly collected new samples and constructed intervals using the same method, approximately 90% of those intervals would contain the true population mean. Therefore, Option 3 correctly identifies the problem with Elise's interpretation.
