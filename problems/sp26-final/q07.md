# BEGIN PROB

Zeyu is wondering whether active bands are more successful than inactive bands, in the sense that they have greater `"top_album_sales"`. To find out, he runs a permutation test on the `bands` DataFrame by comparing the average `"top_album_sales"` for active versus inactive bands using 10,000 shuffles of the `"active"` labels.

# BEGIN SUBPROB

Which of the following best describes the **null hypothesis** for Zeyu's test?

( ) Active bands have higher top album sales than inactive bands, on average.
( ) Active bands and inactive bands have the same distribution of top album sales.
( ) In the full population of all bands, the average top album sales for active bands is higher than that for inactive bands.
( ) In the sample of data in `bands`, the average top album sales for active bands equals the average top album sales for inactive bands.

# BEGIN SOLUTION

**Answer:**

Option 2

**Solution:**

The null hypothesis of a permutation test states that the two groups come from the **same underlying distribution**, so the `"active"` labels are interchangeable under the null. Option 1 describes the alternative hypothesis that active bands have higher sales, while Option 3 also describes a population-level alternative rather than the null. Option 4 is incorrect because the null hypothesis does not require the two groups to have exactly equal sample means; differences can occur due to random variation even when the null is true.

# END SOLUTION

# BEGIN SUBPROB

Complete the code below to run Zeyu's permutation test.

```py
active = bands[bands.get("active") == True].get("top_album_sales")
inactive = bands[bands.get("active") == False].get("top_album_sales")
obs_diff = active.mean() - inactive.mean()

sim_diffs = np.array([])

for i in np.arange(10000):
    shuffled_labels = __(a)__
    shuffled = bands.assign(active=shuffled_labels)
    sim_active = shuffled[shuffled.get("active") == True]
    sim_inactive = shuffled[shuffled.get("active") == False]
    sim_diff = (sim_active.get("top_album_sales").mean()
                - sim_inactive.get("top_album_sales").mean())
    sim_diffs = np.append(sim_diffs, sim_diff)

p_value = __(b)__ / 10000
```

# BEGIN SOLUTION

**Answer:**

- **(a):** `np.random.permutation(bands.get("active"))`
- **(b):** `np.count_nonzero(sim_diffs >= obs_diff)`

**Solution:**

For **(a)**, `np.random.permutation(bands.get("active"))` randomly rearranges the `"active"` labels while keeping the number of active and inactive bands unchanged, breaking any association between activity status and album sales. Each iteration then calculates the difference in mean sales between the shuffled active and inactive groups. For **(b)**, since the alternative hypothesis is that active bands have **higher** average sales, we count simulated differences that are **greater than or equal to** the observed difference using `np.count_nonzero(sim_diffs >= obs_diff)`. Dividing by 10,000 gives the proportion of simulated test statistics at least as extreme as the observed statistic in the direction of the alternative, which is the p-value.

# BEGIN SUBPROB

Suppose Zeyu's p-value turns out to be $0.03$. Which of the following is the correct conclusion of the test at the $0.05$ significance level?

( ) We accept the null hypothesis; active and inactive bands have the same distribution of top album sales.
( ) We fail to reject the null hypothesis; we cannot determine whether the groups differ.
( ) We reject the null hypothesis; active bands have significantly higher top album sales.
( ) We reject the null hypothesis; active and inactive bands have different distributions of top album sales but we can't say which is greater.

# BEGIN SOLUTION

**Answer:**

Option 3

**Solution:**

Since the p-value of $0.03$ is less than the significance level of $0.05$, we **reject the null hypothesis**. Because the alternative hypothesis is one-sided, the test provides statistically significant evidence that active bands have higher average top album sales than inactive bands. Option 1 is incorrect because we do not "accept" the null hypothesis, and Option 2 is incorrect because the p-value is small enough to reject it. Option 4 is incorrect because the direction of the alternative allows us to conclude that active bands have higher average sales, rather than merely concluding that the groups differ.

In Zeyu's permutation test, suppose we change the code to instead shuffle the values in the `"top_album_sales"` column, and rerun the simulation. How would this affect the resulting null distribution?

( ) All 10,000 simulated values would be exactly the same as before.
( ) There would be slight variations in the null distribution but the histogram would look nearly identical.
( ) There would be substantial differences in the null distribution if we were to make this change. The histograms would be noticeably different.
( ) Without the full `bands` DataFrame available, we cannot predict how this change would affect the null distribution.

# BEGIN SOLUTION

**Answer:**

Option 2

**Solution:**

Shuffling the `"active"` labels and shuffling the `"top_album_sales"` values are **statistically equivalent** ways of breaking the association between group membership and album sales while preserving the original group sizes and sales values. Both methods therefore generate the same theoretical null distribution for the difference in group means. However, because the 10,000 simulations are random, the individual simulated differences will not necessarily match between runs, so the resulting histograms should look nearly identical with only slight random variations.
