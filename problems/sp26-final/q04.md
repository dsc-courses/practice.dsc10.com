Austin is analyzing the `"top_album_sales"` column of the `bands` DataFrame, which records each band's best-selling album sales in millions.

# BEGIN SUBPROB

Fill in the blanks so that `[lower, upper]` is the interval that contains all values of `"top_album_sales"` that fall within 2 standard deviations of the mean.

```py
sales = bands.get("top_album_sales")
lower = __(a)__
upper = __(b)__
```

`(a):`

`(b):`

# BEGIN SOLUTION

**Answer:**

- **(a):** `sales.mean() - 2 * np.std(sales)`
- **(b):** `sales.mean() + 2 * np.std(sales)`

**Solution:**

An interval containing all values within 2 standard deviations of the mean extends from **2 standard deviations below the mean** to **2 standard deviations above the mean**. We calculate the mean using `sales.mean()` and the standard deviation using `np.std(sales)`. Therefore, the lower bound is `sales.mean() - 2 * np.std(sales)`, and the upper bound is `sales.mean() + 2 * np.std(sales)`.

# BEGIN SUBPROB

What proportion of `"top_album_sales"` fall in the interval `[lower, upper]`? Choose the best answer below.

( ) Approximately 0.68.
( ) Approximately 0.95.
( ) At least 0.75, but we don't know exactly.
( ) At least 0.88, but we don't know exactly.
( ) We cannot determine anything about this proportion.

# BEGIN SOLUTION

**Answer:**

Option 3: At least 0.75, but we don't know exactly.

**Solution:**

By **Chebyshev's inequality**, for any distribution with a finite standard deviation, the proportion of values within \(k\) standard deviations of the mean is at least \(1-\frac{1}{k^2}\). Setting \(k=2\), we obtain \(1-\frac{1}{2^2}=0.75\), meaning that at least 75% of the values fall within the interval. Options 1 and 2 refer to the empirical rule for approximately normal distributions, but we are not told that `"top_album_sales"` is normally distributed. Option 4 is incorrect because Chebyshev's inequality only guarantees 75% for \(k=2\), while Option 5 is incorrect because we can determine this minimum proportion.
