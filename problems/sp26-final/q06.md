Histograms A, B, and C all display the distribution of `"top_album_sales"` for the 400 bands in `bands`, but they use different bins.

Histogram A uses `bins = [0, 10, 20, 30, 40, 50]`, with bar heights as follows:

::: center
| Bin | Height |
|:---:|:---:|
| $[0, 10)$ | 0.03 |
| $[10, 20)$ | 0.02 |
| $[20, 30)$ | 0.01 |
| $[30, 40)$ | 0.03 |
| $[40, 50]$ | 0.01 |
:::

# BEGIN SUBPROB

Histogram B uses `bins = [0, 20, 40, 50]`. Note that not all bins have the same width. What is the height of the **tallest** bar in Histogram B? Give your answer as an **exact decimal**.

::: center
:::

# BEGIN SOLUTION

**Answer:**

0.025

**Solution:**

To find each bar's height in a density histogram, we use $\text{Height} = \frac{\text{Proportion}}{\text{Bin Width}}$, where the proportion is the area of the bar. Since Histogram B combines bins from Histogram A, we can add the areas of the corresponding bars to calculate each new proportion.

::: center
| Bin | Proportion | Width | Height |
|:---:|:---:|:---:|:---:|
| $[0, 20)$ | 0.50 | 20 | 0.025 |
| $[20, 40)$ | 0.40 | 20 | 0.020 |
| $[40, 50]$ | 0.10 | 10 | 0.010 |
:::

The tallest bar is $[0, 20)$, with a height of **0.025**.

# END SOLUTION

# BEGIN SUBPROB

Histogram C uses `bins = [0, 5, 10, 50]`, again of varying widths. Let $h_1$ be the height of the leftmost bar, $[0, 5)$. What are the minimum and maximum possible values of $h_1$? Give your answers as **exact decimals**.

::: center
minimum $h_1$: maximum $h_1$:
:::

# BEGIN SOLUTION

**Answer:**

- **Minimum $h_1$:** 0
- **Maximum $h_1$:** 0.06

**Solution:**

In Histogram A, the $[0, 10)$ bin has a height of 0.03 and a width of 10, so its area (proportion) is $0.03 \times 10 = 0.30$. When this bin is divided into $[0, 5)$ and $[5, 10)$, we do not know how the 0.30 proportion is distributed between the two smaller bins. The **minimum** possible height occurs when none of the data falls in $[0, 5)$, giving $h_1 = \frac{0}{5} = 0$. The **maximum** possible height occurs when all 0.30 of the proportion falls in $[0, 5)$, giving $h_1 = \frac{0.30}{5} = 0.06$.

# END SOLUTION
