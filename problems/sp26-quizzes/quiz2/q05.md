# BEGIN PROB

Suppose `d` is an array of length 40, containing integers representing
the damage done by each card in `cards`. Likewise, suppose `c` is an
array of length 40, containing integers representing the cost of each
card in `cards`. Fill in the blanks below to calculate the number of
cards, `n`, for which the damage is more than $400$ times the cost.

    n = __(a)__
    for i in np.arange(__(b)__):
        if d[i] > 400 * c[i]:
            n = __(c)__

# BEGIN SOLUTION

`(a)`: $0$ \

`(b)`: `len(d)` or `len(c)` or `40` \

`(c)`: `n + 1`

Part (a): We initialize n to $0$ because it represents the number of cards satisfying the condition, and we have not counted any cards yet. As we examine each card, we will increase n whenever its damage is greater than $400$ times its cost.

Part (b): We use `len(d)` in `np.arange(len(d))` to generate the indices needed to examine every card. Since d contains $40$ elements, `np.arange(len(d))` generates the integers from $0$ to $39$. These indices allow us to access the corresponding damage and cost values using `d[i]` and `c[i]`. Using `len(c)` or $40$ would also work because both arrays contain $40$ elements.

Part (c): We use `n + 1` to increase the counter whenever a card satisfies `d[i] > 400 * c[i]`. The condition checks whether the damage of the card at index i is strictly greater than $400$ times its cost. If the condition is true, the counter increases by one. Otherwise, the counter remains unchanged. After the loop finishes examining all 40 cards, n contains the total number of cards satisfying the condition.
