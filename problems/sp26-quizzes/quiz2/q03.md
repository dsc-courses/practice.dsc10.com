`(b)`: `cards.get("arena_unlocked").apply(make_unlock)`

Part (b): We use `cards.get("arena_unlocked")` to select the Series containing the arena numbers for all cards. Applying `.apply(make_unlock)` calls the function on each value in this Series, converting every arena number into its corresponding string. For example, an arena value of 5 becomes `"Arena 5"`.
