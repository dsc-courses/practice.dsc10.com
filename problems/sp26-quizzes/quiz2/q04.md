Fill in the blanks below so the code prints the `"type"` and `"rarity"`
combination for which the average `"damage"` is greatest.

    grouped = (cards.groupby(__(a)__).mean().reset_index()
                    .sort_values(by=__(b)__, ascending=__(c)__))
    print("type", grouped.get("type").iloc[0])
    print("rarity", grouped.get("rarity").iloc[0])

# BEGIN SOLUTION

`(a)`: `["type", "rarity"]` \

`(b)`: `"damage"` \
 
`(c)`: `False`

Part (a): We use `groupby(["type", "rarity"])` because we want to calculate the average damage for each unique combination of card type and rarity. Grouping by both columns creates a separate group for every combination, such as "troop" and "rare" or "spell" and "epic". Applying `.mean()` then calculates the average damage within each group. The `.reset_index()` method moves "type" and "rarity" back into regular columns so they can be accessed later using `.get()`.

Part (b): We use "damage" in `.sort_values(by="damage", ...)` because our goal is to identify the type and rarity combination with the greatest average damage. After grouping and calculating the means, the "damage" column contains the average damage for each combination. Sorting by this column allows us to compare these averages.

Part (c): We use False for ascending because we want to sort the average damage values from highest to lowest. This places the combination with the greatest average damage in the first row. Finally, `grouped.get("type").iloc[0]` and `grouped.get("rarity").iloc[0]` retrieve the type and rarity from that first row, giving the combination with the highest average damage.
