# BEGIN PROB

Suppose we define `x` as follows.

    x = wc.get(["year", "score"]).groupby("year").mean().shape[0]

Choose the expression below that evaluates to `True`.

( ) `x < wc.shape[0]`
( ) `x == wc.shape[0]`
( ) `x > wc.shape[0]`

# BEGIN SOLUTION

**Answer**: `x == wc.shape[0]`
