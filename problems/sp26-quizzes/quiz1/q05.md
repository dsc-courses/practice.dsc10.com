# BEGIN PROB

Determine the value of `best` after running the code below.

    best = "Ronaldo"
    a = "it's almost time for the World Cup!"
    a = a.split(" ")[0]
    m = "message"
    m = m.title().replace("age", "i")
    best = best[2] + best[-1] + " " + a + " " + m

**Hint**: We can access individual characters from a string in the same
way we access individual elements from an array. For example,
`"hello"[4]` is `"o"`.

# BEGIN SOLUTION

**Answer**: `"no it's Messi"`

Explanation:

Step 1: The variable best is initially assigned the string "Ronaldo", while a stores the sentence "it's almost time for the World Cup!".

Step 2: The expression `a.split(" ")` splits the sentence into a list of words wherever there is a space. The `[0]` then selects the first word from this list. Therefore, a becomes "it's".

Step 3: The variable m is initially assigned "message". Applying `.title()` capitalizes the first letter, changing it to "Message". Next, `.replace("age", "i")` replaces the substring "age" with "i", resulting in "Messi". Therefore, m becomes "Messi".

Step 4: The expression `best[2]` selects the character at index $2$ of "Ronaldo", which is "n", since Python indexing starts at $0$. Similarly, `best[-1]` selects the last character of "Ronaldo", which is "o".

Step 5: Finally, the expression `best[2] + best[-1] + " " + a + " " + m` combines all the strings. Substituting the values gives "n" + "o" + " " + "it's" + " " + "Messi", which evaluates to "no it's Messi".

Therefore, the final value of best is "no it's Messi".
