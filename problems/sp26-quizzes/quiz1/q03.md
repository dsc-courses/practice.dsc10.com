Kate wants to determine how often championships are won in penalty
shoot-outs versus won in regular time. Which plot type would best allow
her to visualize this information?

( ) scatter plot 
( ) bar chart 
( ) line plot

# BEGIN SOLUTION

**Answer**: bar chart

Explanation: The "penalty" column contains Boolean values (True or False) indicating whether a World Cup was decided by a penalty shoot-out. Since we want to compare the number of championships in each category, a bar chart is the most appropriate visualization. Scatter plots are used to examine relationships between numerical variables, while line plots are generally used to display trends across ordered values.

Bianca creates a horizontal bar chart to show how times a World Cup was
won by a team wearing each jersey color. Based on the provided
information, what is the maximum possible length of the `"blue"` bar?
Give your answer as an **integer**.

# BEGIN SOLUTION

**Answer**: $20$

Explanation: The wc DataFrame contains $22$ World Cup winners. From the provided information, we know that two winners wore jerseys that were not blue. To find the maximum possible number of blue jerseys, we assume all the remaining winners wore blue. Therefore, the maximum possible length of the "blue" bar is $22 - 2 = 20$.
