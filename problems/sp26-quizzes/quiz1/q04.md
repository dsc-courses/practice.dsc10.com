`(np.arange(5) + "5")[-1]`

( ) int
( ) float
( ) bool
( ) error

# BEGIN SOLUTION

**Answer**: error

Explanation: `np.arange(5)` creates the integer array `[0, 1, 2, 3, 4]`. The expression attempts to add the string "5" to this integer array. Since NumPy cannot add a string to an array of integers using this operation, an error occurs before `[-1]` can select the last element.

( ) int
( ) float
( ) bool
( ) error

# BEGIN SOLUTION

**Answer**: int 

**Value**: $36$

Explanation: `np.arange(1, 9, 3)` generates the array `[1, 4, 7]`, starting at $1$ and increasing by $3$ without including $9$. Multiplying by $3$ produces `[3, 12, 21]`. Finally, `np.sum()` adds these values to give $36$. Since the result is an integer, the correct answer is Integer, $36$.

`(wc.shape[1] / wc.get("score").iloc[2])`

( ) int
( ) float
( ) bool
( ) error

# BEGIN SOLUTION

**Answer**: float

**Value**: $5.0$

Explanation: `wc.shape[1]` returns the number of columns in the DataFrame, which is $5$. `wc.get("score").iloc[2]` retrieves the third value in the "score" column, which is $1$. Therefore, the expression becomes $5 / 1 = 5.0$. Since Python's `/` operator performs true division, the result is a float.
