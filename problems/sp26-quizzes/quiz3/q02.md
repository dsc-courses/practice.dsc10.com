Elise tends to be most active during the afternoon. Fill in the blanks below to produce 10,000 bootstrapped estimates of Elise's mean jumping distance during the afternoon. Store these estimates in the array `aft_means`.

    aft = elise[__(a)__]
    aft_means = np.array([])

    for i in np.arange(10000):
        resample = __(b)__
        estimate = resample.get("distance").mean()
        aft_means = __(c)__

# BEGIN SOLUTION


`(a)`: `elise.get("time") == "afternoon"`

`(b)`: `aft.sample(aft.shape[0], replace=True)`

`(c)`: `np.append(aft_means, estimate)`

**(a)** We only want to study jumps that occurred during the afternoon. The Boolean condition `elise.get("time") == "afternoon"` selects the corresponding rows.

**(b)** In bootstrapping, we sample from the original data **with replacement**. Each resample should have the same number of rows as the original afternoon DataFrame, which is `aft.shape[0]`.

**(c)** We use `np.append(aft_means, estimate)` to add each bootstrap estimate to the array. Repeating this process 10,000 times produces the bootstrap distribution of the mean afternoon jumping distance.

# BEGIN SUBPROB

Write code to compute the endpoints of a $70\%$ bootstrapped confidence interval for Elise's mean afternoon jumping distance, using the values in `aft_means`.

    left = __(d)__
    right = __(e)__

# BEGIN SOLUTION

`(d)`: `np.percentile(aft_means, 15)`

`(e)`: `np.percentile(aft_means, 85)`

A 70% confidence interval contains the middle 70% of the bootstrap distribution, leaving 30% in the two tails.

We split the remaining 30% equally between the tails, so the endpoints are the 15th and 85th percentiles.

Therefore, we use `np.percentile(aft_means, 15)` for the left endpoint and `np.percentile(aft_means, 85)` for the right endpoint.
