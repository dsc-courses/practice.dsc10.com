# BEGIN PROB

Vanessa authored five of the posts included in `posts`. We define a DataFrame called `vanessa` containing only Vanessa's posts, and keeping only certain columns. This DataFrame is shown in full below.

<center><img src="../assets/images/fa26-midterm/vanessa.png" width=400></center> \

What does the following expression evaluate to?

```py
vanessa.merge(vanessa, left_on="num_likes", right_on="num_comments").shape[0]
```

# BEGIN SOLUTION

**Answer:** `8`

Two left rows with 0 likes each match three right rows with 0 comments, giving 6 matches. The rows with 2 and 3 likes contribute one match each.
