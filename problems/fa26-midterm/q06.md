# BEGIN PROB

Suppose we divide student-authored posts into four categories as follows:

1. public, resolved student-authored posts
2. public, unresolved student-authored posts
3. private, resolved student-authored posts
4. private, unresolved student-authored posts

Fill in the blanks in the code below to create a DataFrame called `max_likes` with four rows and a single column containing the **largest number of likes on a single post** in each of these four categories. The rows can be in any order (not necessarily matching the order given above).

```py
student_posts = posts[__(a)__]
max_likes = student_posts.get(__(b)__).groupby(__(c)__).__(d)__
```

# BEGIN SOLUTION

**Answer:**

- `(a)`: `posts.get("author_role") == "student"`
- `(b)`: `["is_private", "is_resolved", "num_likes"]`
- `(c)`: `["is_private", "is_resolved"]`
- `(d)`: `max()`

First, filter `posts` to include only student-authored posts by checking whether `"author_role"` equals `"student"`.

Next, select the columns `"is_private"`, `"is_resolved"`, and `"num_likes"`, then group by `"is_private"` and `"is_resolved"`. Finally, apply `max()` to find the largest number of likes in each category. Since both grouping columns are Boolean, the result has up to four rows, one for each combination of privacy and resolution status.
