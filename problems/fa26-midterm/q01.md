# BEGIN PROB

Write **one line of code** to create a horizontal bar chart showing both the average `"num_likes"` and the average `"num_comments"` for each `"category"`. On a DataFrame of just the 5 rows shown in the data description, it would look like the image below.

<center><img src="../assets/images/fa26-midterm/bar_chart_sample.png" width=600></center> \

# BEGIN SOLUTION

**Answer:** `posts.get(["category", "num_likes", "num_comments"]).groupby("category").mean().plot(kind="barh")`

Explanation:

Step 1: We use `posts.get(["category", "num_likes", "num_comments"])` to select only the three columns needed for the visualization. The "category" column tells us which category each post belongs to, while "num_likes" and "num_comments" contain the numerical values whose averages we want to calculate. Selecting these columns ensures that our final chart displays only the information requested.

Step 2: We use `.groupby("category")` to group together all posts belonging to the same category. For example, all posts categorized as "Quiz 1" will be grouped together, and all posts categorized as "Projects" will form another group. This allows us to calculate statistics separately for each category.

Step 3: We apply `.mean()` to calculate the average number of likes and comments within each category. Since we selected both "num_likes" and "num_comments", the resulting DataFrame contains two columns: one representing the average likes and the other representing the average comments for each category. The category names become the index labels of this grouped DataFrame.

Step 4: Finally, `.plot(kind="barh")` creates a horizontal bar chart using the grouped DataFrame. Since the DataFrame contains two numerical columns, the chart displays two horizontal bars for each category: one showing the average number of likes and another showing the average number of comments.
