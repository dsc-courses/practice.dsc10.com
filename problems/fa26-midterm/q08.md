# BEGIN PROB

Suppose the array `assignments` contains the names of all assignments in a course. For example, `assignments[0]` might be `"Homework 1"`.

Suppose also that the array `due_dates` contains the deadlines for all assignments in the course, in the same order as in `assignments`. In particular, both arrays have the same length. The entries of `due_dates` are strings formatted like `"YYYY-MM-DD"`. For example, `due_dates[0]` might be `"2026-01-12"`.

Our goal in this problem is to create a string called `reminders` that contains sentences describing when each assignment is due, with one space after each sentence. For example, in a class with only three assignments, the output may look like this:

`"Homework 1 is due on 2026-01-12. Homework 2 is due on 2026-01-17. Midterm Project is due on 2026-01-25. "`

Complete the for-loop below so that `reminders` is a string formatted like the above example, using all the assignments and deadlines in `assignments` and `due_dates`.

```py
reminders = __(a)__
for i in __(b)__:
    reminders = __(c)__
```

# BEGIN SOLUTION

**Answer:**

- `(a)`: `""`
    Our resulting string, reminders, must be initialized as an empty string because when appending sentences to the result, we should not be starting with any extra text.
- `(b)`: `np.arange(len(assignments))` or `np.arange(len(due_dates))`
    The number of iterations in the for loop is determined by the length of either the assignments or due_dates arrays, which will have the same length (per the instructions above). In order to loop through each assignment from the beginning, we create an array using the length of the array, which produces elements starting at index 0 and continues until length - 1, as np.arange(n) stops right before n, giving us exactly len number of elements.
- `(c)`: `reminders + assignments[i] + " is due on " + due_dates[i] + ". "`
    The first part of this statement (reminders)helps us reassign the existing reminders string to the reminders variable, allowing us to append whatever comes after to it. The second part (assignments[i]) allows us to return the corresponding assignment name to the iteration we're on, based on the assignments array. The third part (" is due on ") must have a space before is and after on in order to be correctly spaced when adjoined to the second and fourth parts. The fourth part (due_dates[i]) allows us to return the corresponding due date to the iteration we're on, based on the due_dates array. Finally, the last part (". ") finishes off the sentence with a period and a space that is there to make sure the next sentences that gets appended isn't starting immediately after the period.
