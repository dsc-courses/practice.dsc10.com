# BEGIN PROB

Define a Series containing the first five values in the `"num_comments"` column:

```py
five = posts.take(np.arange(5)).get("num_comments")
```

Determine the value of each of the following expressions.

# BEGIN SUBPROB

`10 + five.sum()`

# BEGIN SOLUTION

**Answer:** `25`

`five` contains the first five values of the `"num_comments"` column, which are 4, 1, 6, 3, and 1. `five.sum()` reduces the Series to a single number: 4 + 1 + 6 + 3 + 1 = 15. Then, 10 is added once to this total, giving 10 + 15 = 25.

# BEGIN SUBPROB

`(10 + five).sum()`

# BEGIN SOLUTION

**Answer:** `65`

Here, the parentheses change the order of operations. `10 + five` adds 10 to every element of the Series, giving a Series with values 14, 11, 16, 13, and 11. Summing these gives 65.

Equivalently, adding 10 to each of the 5 values increases the total by 10 * 5 = 50, so the result is 15 + 50 = 65. The only difference between this part and the previous one is when the 10 is added: once after summing, or to each element before summing.

# BEGIN SUBPROB

`((five + (five >= 5).sum()) >= 5).sum()`

# BEGIN SOLUTION

**Answer:** `2`

It's easiest to evaluate this expression from the inside out.

1. `five >= 5` is an element-wise comparison, giving a Boolean Series with values `False`, `False`, `True`, `False`, `False`.
2. Calling `.sum()` on a Boolean Series counts the number of `True` values, since `True` is treated as 1 and `False` as 0. So `(five >= 5).sum()` evaluates to 1.
3. `five + 1` adds 1 to each element, giving a Series with values 5, 2, 7, 4, 2.
4. Comparing this Series with `>= 5` gives a Boolean Series with values `True`, `False`, `True`, `False`, `False`.
5. Calling `.sum()` counts the `True` values, giving 2.
