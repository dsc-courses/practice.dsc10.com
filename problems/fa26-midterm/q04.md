Suppose we want the function `convert_to_month` to take a string in the format of `"YYYY-MM-DD"` and return the month as an integer. Fill in the blanks in the code below.

```py
def convert_to_month(x):
    return __(a)__(x.__(b)__[1])
```

# BEGIN SOLUTION

**Answer:**

- `(a)`: `int`
- `(b)`: `split("-")`

Explanation:

Part (a): We use `int()` because the function must return the month as an integer rather than a string. Even though the date is stored as text, such as "2026-02-03", the final result should be the integer $2$, not the string "02". Applying `int()` converts the extracted month into the required data type.

Part (b): We use `.split("-")` to separate the date string wherever a hyphen appears. For example, `"2026-02-03".split("-")` produces the list `["2026", "02", "03"]`. Since Python indexing starts at $0$, `[1]` selects the second element, "02", which represents the month. Combining this with `int()` converts "02" into the integer $2$.

Next, we want `post_months` to evaluate to a Series with the month (as an integer) that each post was made on Campuswire, in the same order as the rows appear in the DataFrame. Fill in the blanks in the code below.

```py
post_months = posts.__(c)__.__(d)__
```

# BEGIN SOLUTION

**Answer:**

- `(c)`: `get("date")`
- `(d)`: `apply(convert_to_month)`

Part (c): We use `posts.get("date")` to retrieve the "date" column as a Series. Each value in this Series is a date stored as a string in the format "YYYY-MM-DD". We need this Series because our goal is to extract the month from every post's date.

Part (d): We use `.apply(convert_to_month)` to apply our function to every date in the Series. The function extracts the month from each date and converts it into an integer. For example, "2026-02-03" becomes $2$, while "2026-11-15" becomes $11$. Since `.apply()` preserves the order of the Series, the resulting post_months Series contains the months in the same order as the original posts.
