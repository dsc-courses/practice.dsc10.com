True or False: `int(3.4)` and `round(3.4)` evaluate to the same value.

( ) True 
( ) False

# BEGIN SOLUTION

**Answer**: `True`

`int` drops everything after the decimal point, so `int(3.4)` is `3`. `round` goes to the nearest integer. Since 3.4 is closer to 3 than to 4, `round(3.4)` is also `3`.

# BEGIN SUBPROB

True or False: For any float `x`, `int(x)` and `round(x)` evaluate to
the same value.

( ) True 
( ) False

# BEGIN SOLUTION

**Answer**: `False`

`int` always drops the decimal part, but `round` can round up. For example, `int(3.7)` is `3`, but `round(3.7)` is `4`.
