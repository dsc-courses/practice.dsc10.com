Consider the following code.

    iris = 3 / 1
    poppy = 8 - 6
    daisy = np.array([8, 1, 5])
    lily = np.array([4, 2])
    poppy = iris ** iris - iris * poppy

# BEGIN SUBPROB

What is the value of `poppy` after this code is executed?

# BEGIN SOLUTION

**Answer**: `21.0`

`iris` is `3.0`, because `/` always gives a `float`. `poppy` is `2`.

The last line uses these values: `3.0 ** 3.0 - 3.0 * 2`.

The exponent comes first: `27.0`. Then the multiplication: `6.0`. Then the subtraction: `27.0 - 6.0 = 21.0`.

The answer is a `float` because `iris` is a `float`.

# BEGIN SUBPROB

What is the result of the expression `daisy + lily`?

( ) `array([8, 1, 5, 4, 2])`
( ) `array([12, 3, 5])`
( ) `array([12, 3])`
( ) This expression errors.

# BEGIN SOLUTION

**Answer**: Option D

Adding two arrays adds them position by position: first plus first, second plus second, and so on. `daisy` has 3 elements and `lily` has only 2, so the third element has nothing to pair with, and Python raises an error. Option A is wrong because `+` never joins two arrays together.
