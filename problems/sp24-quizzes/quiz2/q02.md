Fill in the blanks in the code below to find the name of the artist in
`art` who has the lowest mean price of art pieces.

```py
art.groupby(___(x)___).___(y)___.sort_values(by="price").index[0]
```


# BEGIN SOLUTION

**Answer**: (x): `"artist"`, (y): `mean()`

Grouping by `"artist"` gives one row per artist. `.mean()` finds each artist's average price. Sorting by `"price"` puts the lowest average first. After a groupby, the index is the artist names, so `.index[0]` is the artist with the lowest mean price.

**Note:** In newer versions of babypandas, `.mean()` raises an error if the DataFrame has a column that isn't numeric, like `"title"`. To run this code today, first keep only the columns you need: `art.get(["artist", "price"]).groupby("artist").mean()`.

# BEGIN SUBPROB

Fill in the blanks in the code below to find the name of the artist in
`art` who made the most art pieces in a single year.

```py 
(art.groupby(___(x)___).___(y)___.reset_index()
        .sort_values(by="title", ascending=False)
        .get("artist").iloc[0])
```

# BEGIN SOLUTION

**Answer**: (x): `["artist", "year"] or ["year", "artist"]`, (y): `count()`

We need the number of pieces each artist made in each year, so we group by both columns. That gives one row for each artist and year. `.count()` counts the pieces in each group, so every column, including `"title"`, holds that count. Sorting by `"title"` in descending order puts the biggest count first. `.reset_index()` turns `"artist"` back into a column, so `.get("artist")` works. If we grouped by `"artist"` alone, we would count each artist's pieces across all years, not in a single year.
