# BEGIN PROB

Which of the following statements are true in general? Select all that apply.

[ ] Parameters are fixed, but statistics can change depending on the sample.
[ ] Parameters and statistics can both fluctuate depending on the sample.
[ ] For simple random samples, statistics give better estimates of parameters when the sample size is larger.
[ ] The distribution of a statistic is the same regardless of the sample size.
[ ] None of the above.

# BEGIN SOLUTION

**Answer**: Options 1 and 3

A **parameter** is a number that describes the population, like the true mean of every value in it. There's only one population, so a parameter is fixed. A **statistic** is calculated from a sample. Different random samples contain different individuals, so a statistic changes from sample to sample. This makes Option 1 true and Option 2 false.

Option 3 is true. A bigger simple random sample is more representative of the population, so the statistic tends to land closer to the parameter. In other words, the distribution of the statistic is narrower for larger samples.

That's also why Option 4 is false. The distribution of a statistic depends on the sample size. With small samples it is spread out, and with large samples it is concentrated more tightly around the parameter.
