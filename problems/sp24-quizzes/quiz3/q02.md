# BEGIN SUBPROB

You are interested in estimating the average `"meal_price"` across all
Italian restaurants in San Diego County using only the data in
`restaurants`. Fill in the following code so that `italian_means`
evaluates to an array of 1000 bootstrapped estimates for this parameter.

```py
    def bootstrap_means(data, n_samples):
        means = np.array([])
        for i in range(n_samples):
            resample = data.sample(__(a)__, replace = __(b)__)
            means = np.append(means, __(c)__)
        return means

    italian_restaurants = __(d)__
    italian_means = bootstrap_means(italian_restaurants, __(e)__)
```

# BEGIN SOLUTION

**Answer**: \
(a): `data.shape[0]` \
(b): `True` \
(c): `resample.get("meal_price").mean()` \
(d): `restaurants[restaurants.get("cuisine") == "Italian"]` \
(e): `1000`

(a) and (b): Bootstrapping means resampling from our original sample. Each resample should be the **same size** as the original sample, `data.shape[0]`, and drawn **with replacement**. If we sampled without replacement, every resample would just be the original sample in a different order, and every mean would be the same.

(c): For each resample, we want the statistic we're estimating, which is the mean `"meal_price"`. We append it to `means`.

(d): We only care about Italian restaurants, so we query `restaurants` to keep the rows where `"cuisine"` is `"Italian"` before bootstrapping. Our original sample is the Italian restaurants in `restaurants`, and that's the data we resample from.

(e): The second argument, `n_samples`, controls how many times the loop runs, which is how many bootstrapped estimates we get. We want 1000.

# BEGIN SOLUTION

**Answer**: \
(a): `6` \
(b): `94`

An 88% confidence interval captures the middle 88% of the bootstrapped estimates. That leaves $100 - 88 = 12$ percent outside the interval, split evenly between the two tails: $6\%$ below and $6\%$ above. So the lower bound is the 6th percentile and the upper bound is the $100 - 6 = 94$th percentile.

# BEGIN SUBPROB

Suppose `italian_CI` evaluates to \[25, 35\]. Which of the following
statements are correct? Select all that apply.

[ ] If we randomly selected 1000 Italian restaurants from the population of Italian restaurants in San Diego County, about 880 of them will have an average `"meal_price"` &nbsp;between $25 and $35.
[ ] There is an 88% chance that the average `"meal_price"` of Italian restaurants in San Diego County falls between \$25 and \$35.
[ ] 88% of all Italian restaurants have an average `"meal_price"` between $25 and $35.
[ ] None of the above.

# BEGIN SOLUTION

**Answer**: Option 4: None of the above.

A confidence interval estimates a **parameter**, here the average `"meal_price"` across all Italian restaurants in San Diego County. It doesn't describe individual restaurants, and it doesn't put a probability on the parameter.

- **Option 1** is about the meal prices of individual restaurants: about 880 out of 1000 restaurants fall in the range. The interval is about the **mean** of the population, not where individual restaurants' prices fall.
- **Option 2** is the most common mistake. The true average is a fixed number. It is either between \$25 and \$35 or it isn't, so there's no 88% chance about it. The 88% describes the **process**: if we collected many samples and built an interval from each one, about 88% of those intervals would contain the true average.
- **Option 3** describes individual restaurants again, the same mistake as Option 1. Individual meal prices are much more spread out than the sample mean, so far fewer than 88% of restaurants would fall in this narrow range.
