# BEGIN PROB

Suppose that the trees on UCSD's campus are 35% eucalyptus, 25% pine,
and the remaining 40% some other variety. Write **one line of code** to
simulate the act of randomly sampling 40 trees from this distribution,
with replacement. Your code should output an array of length 3 where the
elements represent the number of eucalyptus, pine, and other trees,
respectively.

# BEGIN SOLUTION

**Answer**: `np.random.multinomial(40, [0.35, 0.25, 0.40])`

`np.random.multinomial(n, pvals)` simulates drawing `n` items at random, with replacement, from a categorical distribution with probabilities `pvals`. It returns an array of **counts**, one for each category, in the same order as `pvals`. Here we draw 40 trees, and the probabilities are listed in the order eucalyptus, pine, other. The counts in the result always add up to 40.

`np.random.choice(["eucalyptus", "pine", "other"], 40, p=[0.35, 0.25, 0.40])` would simulate the same sampling, but it returns 40 individual labels instead of 3 counts. Getting counts from it would take more than one line.
