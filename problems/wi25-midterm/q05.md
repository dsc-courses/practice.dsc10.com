# BEGIN PROB

It's the grand opening of UCSD's newest dining attraction: The Bread
Basket! As a hardcore bread enthusiast, you celebrate by eating as much
bread as possible. There are only a few menu items at The Bread Basket,
shown with their costs in the table below:

    **Bread**    **Cost**
  ------------- ----------
    Sourdough       2
   Whole Wheat      3
   Multigrain       4

Suppose you are given an array `eaten` containing the names of each type
of bread you ate.

For example, `eaten` could be defined as follows:

```py
    eaten = np.array(["Whole Wheat", "Sourdough", "Whole Wheat", 
                      "Sourdough", "Sourdough"])
```

In this example, `eaten` represents five slices of bread that you ate,
for a total cost of $\$12$. Pricey!

In this problem, you’ll calculate the total cost of your bread-eating extravaganza in various ways. Unless otherwise instructed, your code must calculate the total cost for an arbitrary `eaten` array, which might not be exactly the same as the example shown above.

# BEGIN SOLUTION

**Answer (a):** `np.array([4, 3, 2])` or `[4, 3, 2]` or equivalent

For our solution, we need to consider a few things. First, since we're grouping by `"Eaten"`, we need to
consider that groupby, when grouping by strings (like "Whole Wheat" and "Sourdough"), sorts them alphabetically by default. That means that if we have a DataFrame containing "Sourdough", "Whole Wheat", and "Multigrain", the grouped DataFrame will be indexed by `"Eaten"` in the order of "Multigrain", then "Sourdough", then "Whole Wheat".

Then, when we are getting the counts of each of those types, we want to multiply how many of each type there are by their respective price. If we know they'll be sorted in alphabetical order, we want our price array or list to match that; in other words, it should have "Multigrain"'s price first, then "Sourdough", then "Whole Wheat". So that is why we need the array to be 4, 3, then 2. 

**Answer (b):** `.sum()`

We want to get the respective cost for each loaf; how much we spent on Multigrain, Sourdough, and Whole Wheat, but we then need to add those individual totals together to get our total cost. `.sum()` allows us to do this.
