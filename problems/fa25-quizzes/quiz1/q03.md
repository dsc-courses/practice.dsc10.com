# BEGIN PROB

You decide to eliminate some of the fighters that have `"Sword"` as
their `"Weapon"`. **Select all** expressions that evaluate to the total
number of such fighters.

[ ] `smash[smash.get("Weapon") == "Sword"].shape[0]`
[ ] `smash.get("Weapon").count("Sword")`
[ ] `(smash.get("Weapon") == "Sword").shape[0]`
[ ] `smash[smash.get("Weapon") == "Sword"].sum()`
[ ] `smash.groupby("Weapon").count().get("Franchise").loc["Sword"]`
[ ] None of the above.

# BEGIN SOLUTION

**Answer**: Options 1 and 5.

Option 1: smash[smash.get("Weapon") == "Sword"].shape[0] The comparison makes a Boolean Series, and querying it using brackets keeps only the Sword rows. .shape[0] is the number of rows left, which is the number of sword fighters.

Option 5: smash.groupby("Weapon").count().get("Franchise").loc["Sword"] Grouping by "Weapon" and counting gives the number of rows in each group in every column. Using the "Franchise" column, then looking up the "Sword" row with .loc, gives the number of sword fighters. Any other column would give the same number.

Options 2, 3, and 4 are wrong.
Option 2: smash.get("Weapon").count("Sword") count on a Series doesn’t take an argument, so this raises an error. (String count does take an argument, but this is a Series, not a string.)

Option 3: (smash.get("Weapon") == "Sword").shape[0] The Boolean Series has one entry for every fighter, True or False. Its shape[0] is the length of the whole Series, which is the total number of fighters. Nothing was filtered. To count the True values you would use .sum().

Option 4: smash[smash.get("Weapon") == "Sword"].sum() The filter is fine, but .sum() on a DataFrame adds up each column separately. It does not count rows, so it doesn’t give a single number of fighters.
