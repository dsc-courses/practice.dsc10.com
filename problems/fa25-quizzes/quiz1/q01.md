    str(len(smash)) * 2.0

( ) int 
( ) float 
( ) str 
( ) bool 
( ) DataFrame 
( ) error

# BEGIN SOLUTION

**Answer**: error

len(smash) returns the number of rows in the DataFrame, as an int. str(...) turns it into a string like "60". You can multiply a string by an int to repeat it ("60" * 2 is "6060"), but not by a float. "60" * 2.0 raises a TypeError, even though 2.0 is a whole number.

# BEGIN SUBPROB

    smash.get("Year").iloc[0] == "1981"

( ) int 
( ) float 
( ) str 
( ) bool 
( ) DataFrame 
( ) error

# BEGIN SOLUTION

**Answer**: bool

smash.get("Year") is a Series of ints, and .iloc[0] pulls out the first value, which is a single int. Comparing an int to the string "1981" doesn’t raise an error. == just returns False, because an int and a string are never equal. A comparison always gives a bool, so the type is bool. If the quiz had used < instead of ==, this would have been an error.
