# BEGIN PROB
For the opening trailer, your boss needs you to find out two facts about
Super Smash Brothers history. Write one line of Python code that
evaluates to each quantity below.

# BEGIN SUBPROB
The median origin `"Year"` of all fighters in `smash`.

# BEGIN SOLUTION

**Answer**: `smash.get("Year").median()`

This gets the "Year" column as a Series, then call .median() on it.

# BEGIN SUBPROB
The name of the fighter with the earliest origin `"Year"` (or in the case of a tie, any fighter from the earliest origin `"Year"`).

# BEGIN SOLUTION

**Answer**: `smash.sort_values(by = "Year").get("Name").iloc[0]` OR `smash.set_index("Name").sort_values(by = "Year").index[0]`

Sort the table by "Year", which goes from smallest to largest by default, so the earliest fighter ends up in the first row. Then grab the name at position 0.

In the first version, .get("Name") gets the Name column and .iloc[0] takes the first value.
In the second version, set_index("Name") moves the names into the index, so .index[0] gives the first name after sorting.

You can’t use .loc[0] for this. Sorting rearranges the rows but keeps their original labels, so .loc[0] would find whichever fighter was originally in row 0, not the earliest one.
