# BEGIN PROB

For diversity, we need to cut fighters from the most common `"Species"`.
Fill in the blanks below to find the `"Species"` with the most fighters (i.e. the `"Species"` most
represented in `smash`).

    smash.groupby("Species").___(a)___().sort_values(by="Year").___(b)___

# BEGIN SOLUTION

`(a):` `count` \

smash.groupby("Species").count() gives one row per species. Every other column holds the number of rows in that group, so the "Year" column now contains the number of fighters of each species. The column’s name is a leftover from the original data, but the values are counts.

`(b):` `index[-1]`

.sort_values(by="Year") sorts these counts from smallest to largest, so the species with the most fighters ends up in the last row. The species names are in the index, so index[-1] gives the name of the last row, which is the most common species.

If you wrote .index[0], you would get the species with the fewest fighters.
