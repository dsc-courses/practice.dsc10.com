# BEGIN PROB

Alongside the unveiling of your new game, you'll want to announce a new
fighter to build hype. The code below calculates the name of this new
fighter and stores it in the variable `new`. In the box, write in the
value of the `new` variable after the code executes. Write clearly!

    lu = "luigi"
    dk = "dk"
    new = "crash"
    dk.replace("k", "kong")
    new = ((lu + "t") * len(dk)).title()
    new = new



# BEGIN SOLUTION

**Answer**: `"Luigitluigit"`

dk.replace("k", "kong") creates a new string, "dkong", but the result is never assigned to anything. Strings can’t be changed in place, so dk is still "dk".

len(dk) is 2, because dk is still "dk".

lu + "t" is "luigit".

"luigit" * 2 repeats it, giving "luigitluigit".

.title() capitalizes the first letter of each word. There are no spaces, so the whole thing counts as one word and only the first letter changes, giving "Luigitluigit".

new = new does nothing.
