# BEGIN PROB

We want to take a simple random sample (SRS) of 10 ice cream orders from the `orders` DataFrame. Which of the following samples produce a SRS? **Select only one of the options.**

( ) `orders.sample(10, replace=True)`
( ) `orders.take(np.arange(10))`
( ) `orders[orders.get("flavor") == "birthday cake"].sample(10)`
( ) None of the above.

# BEGIN SOLUTION

**Answer:** None of the above.

A simple random sample is drawn uniformly at random **without replacement** from the **entire** population.

- `orders.sample(10, replace=True)` samples **with** replacement, so the same order could appear more than once. That is not a simple random sample.
- `orders.take(np.arange(10))` always returns the first 10 rows of `orders`. There's no randomness at all.
- `orders[orders.get("flavor") == "birthday cake"].sample(10)` only samples from birthday cake orders, so orders of any other flavor have no chance of being selected.
