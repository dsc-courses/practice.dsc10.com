# BEGIN PROB

Customers often struggle to pick a flavor. Janine writes the following code to randomly select an ice cream flavor from `flavors`. Note that `np.ones(n)` returns an array of length `n` where every element is `1`.

```py
distA = orders.groupby("flavor").count().get("cone") / orders.shape[0]
distB = np.ones(flavors.shape[0]) / flavors.shape[0]

selection = np.random.multinomial(1, __(i)__) == 1

print(flavors[selection].get("name"))
```

# BEGIN SUBPROB

Which of the following best describes the **type** of `selection` if `(i)` is replaced with `distA`? **Select only one of the options.**

( ) int
( ) bool
( ) boolean array
( ) int array

# BEGIN SOLUTION

**Answer:** boolean array

`np.random.multinomial(1, distA)` returns an **array** of integers with one element per flavor. Since we only draw 1 item, exactly one element is 1 and the rest are 0. Comparing that array to 1 with `== 1` happens element-wise, which gives an array of `True`/`False` values. That's a boolean array, with `True` in the position of the selected flavor.

# BEGIN SUBPROB

What is the code most likely to output if `(i)` is replaced with `distA`? **Select only one of the options.**

( ) The most popular ice cream flavor
( ) The least popular ice cream flavor
( ) The newest ice cream flavor
( ) Every flavor is equally likely to be outputted

# BEGIN SOLUTION

**Answer:** The most popular ice cream flavor

`orders.groupby("flavor").count().get("cone")` gives the number of orders of each flavor. Dividing by `orders.shape[0]` turns these counts into the proportion of all orders that were each flavor. The groupby sorts flavors alphabetically, the same order as `flavors`, so the boolean array `selection` lines up with the rows of `flavors`.

Each flavor is selected with probability equal to its share of orders, so the flavor ordered most often has the highest chance of being printed.

# END SOLUTION

( ) The most popular ice cream flavor

# BEGIN SOLUTION

**Answer:** Every flavor is equally likely to be outputted

`distB` is an array of length `flavors.shape[0]` where every element is `1 / flavors.shape[0]`. That's the uniform distribution over all flavors, so each flavor has the same chance of being selected.
