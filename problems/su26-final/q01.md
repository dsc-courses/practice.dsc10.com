# BEGIN PROB

The Parlor uses a fixed pricing for each order. The function `get_price` takes two arguments: the number of scoops (an `int`) and whether the ice cream was served in a cone (a `bool`). You may assume that a customer can order no more than 4 scoops of ice cream. `get_price` should return the price (a `float`) that would appear in the `"price"` column of `orders` for an ice cream with the same attributes.

Example inputs and outputs are given below.

```py
>>> get_price(2, True)
7.50
>>> get_price(2, False)
6.00
>>> get_price(4, True)
13.50
```

Consider the following four function definitions.

**Option 1:**

```py
def get_price(scoops, cone):
    return np.arange(0, 5 * 2, 2)[scoops] + (cone * 1.5)
```

**Option 2:**

```py
def get_price(scoops, cone):
    return np.arange(0, 4 * 3, 3)[scoops] + (cone * 1.5)
```

**Option 3:**

```py
def get_price(scoops, cone):
    return np.arange(0, 5 * 3, 3)[scoops] + (cone * 1.5)
```

**Option 4:**

```py
def get_price(scoops, cone):
    return np.arange(3, 5 * 3, 3)[scoops] + (cone * 1.5)
```

Which of the above functions correctly defines `get_price`? **Select only one of the options.**

( ) Option 1
( ) Option 2
( ) Option 3
( ) Option 4

# BEGIN SOLUTION

**Answer:** Option 3

From the examples, a cup costs \$3.00 per scoop (`get_price(2, False)` is 6.00), and a cone adds \$1.50 (`get_price(2, True)` is 7.50). Since `True` behaves like 1 and `False` behaves like 0 in arithmetic, `cone * 1.5` adds 1.5 for a cone and 0 for a cup. So we need an array where the element at position `scoops` is `3 * scoops`.

- **Option 3:** `np.arange(0, 5 * 3, 3)` is `[0, 3, 6, 9, 12]`. Position 2 holds 6 and position 4 holds 12, so `get_price(4, True)` is $12 + 1.5 = 13.5$. ✅
- **Option 1:** `np.arange(0, 5 * 2, 2)` is `[0, 2, 4, 6, 8]`, so `get_price(2, False)` would be 4, not 6.
- **Option 2:** `np.arange(0, 4 * 3, 3)` is `[0, 3, 6, 9]`, which has only 4 elements, so `[4]` causes an error for a 4-scoop order.
- **Option 4:** `np.arange(3, 5 * 3, 3)` is `[3, 6, 9, 12]`, so `get_price(2, False)` would be 9, not 6. Every price is shifted by one scoop.
