Lauren uses some babypandas operations on `orders` to create a new DataFrame called `by_temp`. The first few rows of `by_temp` are shown below, though `by_temp` has many more rows than shown.

| temp | revenue |
|---|---|
| **75** | 736.50 |
| **76** | 821.50 |
| **77** | 849.00 |
| **78** | 962.50 |

This DataFrame contains the average `revenue` per day from all ice creams sold on days with the corresponding `temp`.

Lauren initially attempted to define the DataFrame `by_temp` with the following code. The code is **incorrect**.

```py
# line 1:
relevant = orders.get(["temp", "price", "days"])

# line 2:
by_day = relevant.groupby("days").sum()

# line 3:
by_temp = by_day.reset_index().groupby("temp").mean()

# line 4:
by_temp = by_temp.assign(revenue=by_temp.get("price")).get(["revenue"])
```

# BEGIN SUBPROB

<!-- a) (X pts) -->

Which of the following best describes the value `by_day.get("temp").loc[0]`? **Select only one of the options.**

( ) A\. The number of orders on opening day
( ) B\. The temperature on opening day
( ) C\. The temperature on opening day times the number of orders on opening day
( ) D\. The total revenue on opening day

# BEGIN SOLUTION

**Answer:** C. The temperature on opening day times the number of orders on opening day.

Firstly, notice the `"days"` column in the `orders` DataFrame. It has repeating values.

Every order on a given day has the same `"temp"` value. Line 2 groups the orders by `"days"` and sums their `"temp"` values, adding one copy of the temperature for every order.

So Lets say if there were 5 orders for `days == 0`, and the temperature was 80, Line 2 would basically sum 80 five times, meaning 80*5. 

 Since opening day has `days == 0`, `.loc[0]` selects that day's sum.

<!-- b) (X pts) -->

Which of the following changes would fix the code that Lauren wrote to correctly produce `by_temp`? **Select only one of the options.**

( ) A\. Change line 2: `by_day = relevant.groupby(["days", "temp"]).mean()`
( ) B\. Change line 2: `by_day = relevant.groupby(["days", "temp"]).sum()`
( ) C\. Change line 3: `by_temp = by_day.reset_index().groupby(["days", "temp"]).sum()`
( ) D\. Change line 3: `by_temp = by_day.reset_index().groupby(["days", "temp"]).mean()`

# BEGIN SOLUTION

**Answer:** B. Change line 2 to `by_day = relevant.groupby(["days", "temp"]).sum()`.

Each day has one temperature, so grouping by `["days", "temp"]` produces one group per day and keeps the temperature as part of the group's index. Summing `"price"` within each group gives that day's total revenue.

In line 3, `.reset_index()` puts `"temp"` back in a column. `.groupby("temp").mean()` then averages the daily revenue totals across days with the same temperature, giving each day one contribution to the mean. Line 4 keeps those averages in the `"revenue"` column.

Option A would compute a mean order price for each day. Options C and D retain the summed temperatures from line 2 and keep different days in separate groups.
