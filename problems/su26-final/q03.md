# BEGIN PROB

Consider the following code:

```py
orders_count = orders.shape[0]
flavors_count = flavors.shape[0]

merged = flavors.merge(orders, left_on="name", right_on="flavor")
merged_count = merged.shape[0]
```

# BEGIN SUBPROB

Which of the following expressions evaluate to `True`? **Select only one of the options.**

( ) `flavors_count > orders_count`
( ) `flavors_count < orders_count`
( ) `flavors_count == orders_count`

# BEGIN SOLUTION

**Answer:** `flavors_count < orders_count`

`flavors` has exactly one row per flavor. Every flavor has been sold at least once, so every flavor shows up in at least one row of `orders`. Many flavors are ordered many times (for example, `"raspberry lemon"` already appears twice in the first five rows of `orders`), so `orders` has more rows than `flavors`.

# END SOLUTION

# BEGIN SUBPROB

Which of the following expressions evaluate to `True`? **Select only one of the options.**

( ) `orders_count > merged_count`
( ) `orders_count < merged_count`
( ) `orders_count == merged_count`

# BEGIN SOLUTION

**Answer:** `orders_count == merged_count`

When merging, each row of `orders` is matched with every row of `flavors` that has the same flavor name. Each flavor appears exactly once in `flavors`, and every flavor in `orders` is one The Parlor offers, so it appears in `flavors`. That means each row of `orders` matches **exactly one** row of `flavors`. No rows are dropped and no rows are duplicated, so `merged` has the same number of rows as `orders`.
