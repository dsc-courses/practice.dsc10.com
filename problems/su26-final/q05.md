# BEGIN PROB

Noah has been working the register this week and puts together a dataset of all ice cream orders from this week. The DataFrame `week` contains every ice cream sold this week and has all of the same columns as `orders`. Due to administrative permissions, Noah does not have access to the `orders` DataFrame.

Consider the following bootstrap code which uses the `week` DataFrame.

```py
estimates = np.array([])
for i in np.arange(10000):
    estimate = 0
    for j in np.arange(100):
        value = week.sample(1).get("scoops").iloc[0]
        estimate += value
    estimates = np.append(estimates, estimate * 0.01)
```

# BEGIN SUBPROB

**True or False:** The `week` DataFrame is your population in this example.

( ) True
( ) False

# BEGIN SOLUTION

**Answer:** False

The population is every ice cream order since The Parlor opened, which is the data in `orders`. Noah doesn't have access to `orders`, so he uses `week`, a **sample** of orders from one week, and bootstraps from it to estimate a parameter of the population.

# END SOLUTION

# END SUBPROB

# BEGIN SUBPROB

What population parameter is being estimated by the bootstrap code?

# BEGIN SOLUTION

**Answer:** The mean number of scoops per order among all orders at The Parlor (the mean of the `"scoops"` column in `orders`).

In each iteration of the outer loop, the inner loop adds up 100 randomly selected `"scoops"` values. Multiplying that sum by `0.01` is the same as dividing by 100, so each `estimate` is the **mean** number of scoops in a resample. These means estimate the mean number of scoops per order in the population.

# END SOLUTION

# END SUBPROB

# BEGIN SUBPROB

What is the size of every resample generated by the bootstrap code? **Give your answer as an int.**

# BEGIN SOLUTION

**Answer:** 100

Each resample is built one row at a time in the inner loop, which runs 100 times. Every call to `week.sample(1)` picks one row from all of `week`, independently of previous picks. So the same row can be selected more than once, which means the resample is drawn **with replacement**. Each resample has 100 values.

# END SOLUTION

# END SUBPROB

# BEGIN SUBPROB

Suppose we were to plot a histogram of `estimates`. Which of the following best describes this histogram? **Select only one of the options.**

( ) The histogram reflects the shape of the population.
( ) The histogram reflects the shape of the sample.
( ) The histogram is roughly normal because of the Central Limit Theorem (CLT).
( ) The shape of the histogram cannot be determined.

# BEGIN SOLUTION

**Answer:** The histogram is roughly normal because of the Central Limit Theorem (CLT).

Each element of `estimates` is the **mean** of a random sample of 100 values drawn with replacement. The CLT says that the distribution of sample means is roughly normal for large samples, no matter what the shape of the original data looks like. So the histogram of `estimates` is roughly normal (bell-shaped), not shaped like the population or the sample.

# END SOLUTION
