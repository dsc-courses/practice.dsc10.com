# BEGIN PROB

Using `ghibli`, write one line of code that outputs a DataFrame
describing how many films of each genre each director has directed.

# BEGIN SOLUTION

**Answer:** `ghibli.groupby(["Director", "Genre"]).count()`

**Solution:**
We want to know how many films are of **each genre** for **each director**. The use of the word "each" suggests that we want to use `groupby` here with the attributes `Director` and `Genre`. To do this, we pass an array of columns that we want to group by. this is where `["Director", "Genre"]` comes from. Now, our DataFrame has one row for every director-genre combination, which is what we want. We want to know **how many** films are present in each combination. This means that we want to use `.count()`, which counts the number of films that are of a specific director-genre combination.
