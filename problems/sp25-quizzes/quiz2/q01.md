**Answer (a):** `int(mins / 60)`

**Solution (a):**
The number of hours in general can be given by dividing the number of minutes by 60 (since there are 60 minutes per hour). This is where we get `mins / 60` from. This is where int() comes from.

**Answer (b):** `mins % 60`

**Solution (b):**
Because we calculated the number of **whole** hours in the previous part, we are interested in calculating the _remaining_ minutes leftover. We can use the `%` operator (modulus), which calculates the remainder of a division between two numbers. Like the previous part, we know that there are 60 minutes in an hour. We want to find the remaining minutes that are leftover from this division. This is where we get `mins % 60` from.
