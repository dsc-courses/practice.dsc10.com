# BEGIN PROB

Fill in the blanks so the expression below evaluates to the name of the
chest that contains the most **distinct** items.

```py

    (items.groupby(___(a)___).___(b)___
          .sort_values(by="Quantity", ascending=___(c)___).___(d)___)
```

# BEGIN SOLUTION

**Answer:**

- **\(a\) `"Chest"`**
- **\(b\) `count()`**
- **\(c\) `False`**
- **\(d\) `index[0]`**
**Solution:**

We first use `groupby("Chest")` to group items that are stored in the same chest. Next, we use `.count()` to count the number of **distinct** items in each chest. Each row now represents a single chest and the number of **distinct** items within it. The `"Quantity"` column contains the number of distinct items in each chest, while the index contains the chest names. We then use `.sort_values(by="Quantity", ascending=False)` to sort the chests in **descending order** by their number of distinct items. Because we sorted by descending order, the chest with the most distinct items is the first row. This is why `.index[0]` retrieves our desired answer. Sorting by ascending order and selecting the last row (`.index[-1]`) would've worked as well.
