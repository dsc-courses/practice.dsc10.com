# BEGIN PROB

Which of the following expressions evaluates to the number of
`"Emerald"`s in Steve's chests? Select all that apply.
 

[ ] `items.get("Quantity").loc["Emerald"]`
[ ] `(items[items.get("Item") == "Emerald"].sort_values(by="Quantity").loc["Emerald"])`
[ ] `items.sort_values(by="Quantity").get("Quantity").iloc[0]`
[ ] `items[items.index == "Emerald"].get("Quantity").iloc[0]`
[ ] None of the above.

# BEGIN SOLUTION

**Answer:**

Option 1 and Option 4

**Solution:**

**Option 1** is correct because `"Item"` is the index of our DataFrame, so `.loc["Emerald"]` retrieves the quantity corresponding to the `"Emerald"` index label. **Option 2** is incorrect because `"Item"` is the index, not a column. Therefore, `items.get("Item")` would error. **Option 3** is incorrect because sorting by `"Quantity"` in ascending order and selecting `.iloc[0]` retrieves the _smallest quantity_ in the DataFrame, which is not necessarily the quantity of Emeralds. **Option 4** is correct because `items.index == "Emerald"` filters the DataFrame to the singular row corresponding to Emeralds, and `.get("Quantity").iloc[0]` retrieves the quantity from that row.
