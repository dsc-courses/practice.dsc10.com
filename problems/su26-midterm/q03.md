# BEGIN PROB

The `"time"` column in `ufo` describes the time at which a UFO was
initially sighted. The times are formatted in 24-hour time which uses
hours `00` through `23`. For example, `13:51` is the same as 1:51 PM.

We want to create a function named `time_of_day` which takes in a time
and returns the corresponding category, defined by the table below.

| hour range | category |
| --- | --- |
| 00:00–04:59 | `"night"` |
| 05:00–11:59 | `"morning"` |
| 12:00–16:59 | `"afternoon"` |
| 17:00–23:59 | `"evening"` |

Example inputs and outputs are given below.

    >>> time_of_day("00:00")
    "night"

    >>> time_of_day("13:37")
    "afternoon"

    >>> time_of_day("23:59")
    "evening"

# BEGIN SUBPROB

Consider the following implementations for `time_of_day`. Which of the
following implementations are correct? **Select all that apply.**

**Implementation 1:**

    def time_of_day(time):
        hour_part = int(time.split(":")[0])
        if hour_part >= 17 or hour_part < 24:
            return "evening"
        elif hour_part >= 12 or hour_part < 17:
            return "afternoon"
        elif hour_part >= 5 or hour_part < 12:
            return "morning"
        else:
            return "night"

**Implementation 2:**

    def time_of_day(time):
        hour_part = int(time.split(":")[0])
        if hour_part < 5:
            return "night"
        if hour_part < 12:
            return "morning"
        if hour_part < 17:
            return "afternoon"
        if hour_part >= 0:
            return "evening"

**Implementation 3:**

    def time_of_day(time):
        hour_part = int(time.split(":")[0])
        if hour_part >= 17:
            return "morning"
        elif hour_part >= 12:
            return "night"
        elif hour_part >= 5:
            return "afternoon"
        else:
            return "evening"

[ ] Implementation 1
[ ] Implementation 2
[ ] Implementation 3

# BEGIN SOLUTION

**Answer:** Implementation 2 only.

All three implementations extract the hour correctly with
`int(time.split(":")[0])`; the difference is in the conditions.

- **Implementation 1:** The conditions use `or` where they should use
  `and`. Every valid hour satisfies `hour_part < 24`, so the very first
  condition `hour_part >= 17 or hour_part < 24` is `True` for *every*
  time, and the function always returns `"evening"`.
- **Implementation 2:** Correct. Because each `if` returns immediately,
  reaching the second `if` already guarantees `hour_part >= 5`, reaching
  the third guarantees `hour_part >= 12`, and reaching the fourth
  guarantees `hour_part >= 17`. So the one-sided comparisons are enough,
  and the categories come out exactly as specified. (The final
  `if hour_part >= 0` is always `True` at that point, so it behaves like
  an `else`.)
- **Implementation 3:** The structure is right, but the returned labels
  are shuffled. Hours $17$ and later should be `"evening"`, not
  `"morning"`.

( ) line plot

( ) bar chart

# BEGIN SOLUTION

**Answer:** Line plot.

The `"time"` column is a sequence of times running from `00:00` to
`23:59`, so it behaves like a numerical variable with a natural order.
Here we're plotting one average duration per time, so we have one
variable (average duration) measured across a sequence — exactly the
situation a line plot is designed for. Line plots are the standard
choice for showing how a quantity changes over time.

A scatter plot would be used for two numerical variables measured on
each individual, a bar chart for a categorical variable, and a histogram
for the distribution of a single numerical variable.

# BEGIN SUBPROB

Which type of data visualization should be used to compare **average
duration** to the new `"time_of_day"` column? **Select only one of the
options.**

( ) line plot
( ) scatter plot
( ) bar chart
( ) histogram

# BEGIN SOLUTION

**Answer:** Bar chart.

Unlike `"time"`, the `"time_of_day"` column is **categorical** — it
takes only the four values `"night"`, `"morning"`, `"afternoon"`, and
`"evening"`. Bar charts are used to show a numerical quantity (here,
average duration) for each category of a categorical variable.

A line plot would incorrectly suggest a continuous trend between
categories, while scatter plots and histograms both require numerical
data.
