# BEGIN SUBPROB

What does `mystery1` evaluate to? Give your answer as an **integer**.

    mystery1 = rural.merge(farms, left_index=True, right_on="zipcode").shape[0]

# BEGIN SOLUTION

**Answer:** `5`

This merge matches the **index** of `rural` (the zip codes `89101`,
`89301`, and `89801`) against the `"zipcode"` **column** of `farms`. A
merge produces one row for every pair of matching rows, so we count the
farms sitting in each of `rural`'s zip codes:

- `89101`: one farm (First Fruits) → $1$ row
- `89301`: two farms (Rolling Horse, Ana's Village) → $2$ rows
- `89801`: two farms (Nevada Hay, Blue Lizard) → $2$ rows

That gives $1 + 2 + 2 = 5$ rows in total. The farms in `89406`,
`89446`, and `89808` don't appear because those zip codes aren't in
`rural`.

# BEGIN SUBPROB

What does `mystery2` evaluate to? Give your answer as an **integer**.

**Hint:** You do not need to know all of the rows in the `ufo` DataFrame.

    mystery2 = ufo.merge(farms, on="zipcode").shape[0]

# BEGIN SOLUTION

**Answer:** `17`

This merge matches the `"zipcode"` column of `ufo` against the
`"zipcode"` column of `farms`. Each sighting in a given zip code pairs
with each farm in that same zip code, so the number of resulting rows is

$$\text{(sightings in that zip code)} \times \text{(farms in that zip code)}$$

summed over all zip codes that appear in both DataFrames.

This is exactly where `rural` comes in: it lists the zip codes appearing
in both `ufo` and `farms`, along with the number of sightings in each.
That's why we don't need to see all of `ufo`.

- `89101`: $1$ sighting $\times$ $1$ farm $= 1$
- `89301`: $5$ sightings $\times$ $2$ farms $= 10$
- `89801`: $3$ sightings $\times$ $2$ farms $= 6$

Altogether, $1 + 10 + 6 = 17$ rows.
