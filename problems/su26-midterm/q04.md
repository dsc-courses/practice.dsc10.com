# BEGIN PROB

Janine was in Las Vegas last year when she spotted a UFO. She remembers
that the UFO was either disk-shaped or cylinder-shaped, but she does not
remember which.

Write a Python expression that evaluates to the time at which this
sighting could have occurred. If there are multiple possible sightings
matching these conditions, your expression should evaluate to the time
of the earliest one.

The zip code of Las Vegas is `"89109"`. The earliest time is the one
with the smallest hour value; ties are broken by the smallest minute
value (i.e. `"00:10"` is earlier than `"23:57"`, `"04:10"` is earlier
than `"04:11"`).

**Hint:** Since `"time"` is a string in `"HH:MM"` format, comparing these
strings alphabetically gives the same result as comparing them
chronologically.

You may write on multiple lines, but your code should represent a
**single expression** in Python.

# BEGIN SOLUTION

**Answer:**

    ufo[(ufo.get("zipcode") == "89109") &
        ((ufo.get("shape") == "disk") |
         (ufo.get("shape") == "cylinder"))].get("time").min()

We build this up one piece at a time.

- `ufo.get("zipcode") == "89109"` is a Boolean Series that is `True` for
  sightings in Las Vegas.
- `(ufo.get("shape") == "disk") | (ufo.get("shape") == "cylinder")` is
  `True` for sightings of either shape Janine might have seen. We use
  `|` (or) here, not `&`, since a single sighting can't be both shapes
  at once — requiring both would leave us with no rows at all.
- Combining the two conditions with `&` keeps only the rows that satisfy
  both, and querying `ufo` with that Series gives the DataFrame of
  candidate sightings.

Note the parentheses around each individual comparison. They're
required, because `&` and `|` have higher precedence than `==` in
Python.

Finally, `.get("time")` pulls out the times of those sightings and
`.min()` finds the smallest one. Thanks to the hint, the alphabetically
smallest `"HH:MM"` string is also the chronologically earliest time, so
`.min()` is exactly what we want.

An equivalent approach sorts instead of using `.min()`:

    ufo[(ufo.get("zipcode") == "89109") &
        ((ufo.get("shape") == "disk") |
         (ufo.get("shape") == "cylinder"))].sort_values("time").get("time").iloc[0]
