# BEGIN PROB

Lauren is a rancher in a small town. She observes that every time a UFO
is sighted, 5 different cows go missing (however, they always eventually
reappear). There are 100 cows in town, and Lauren owns 23 of the 100
cows.

Complete the simulation below to estimate the probability that exactly
two of Lauren's cows are abducted after a UFO sighting. Assume the
missing cows are selected at random from the set of all cows.

Fill in blanks (i), (ii), (iii), and (iv).

    all_cows = np.arange(100)

    repetitions = 10000
    count_event = 0

    for i in np.arange(repetitions):
        abducted = np.random.choice(__(i)__)

        laurens_cows = abducted <= __(ii)__
        n = np.count_nonzero(laurens_cows)

        if __(iii)__:
            count_event = count_event + 1

    prob = __(iv)__

# BEGIN SOLUTION

**Answer (i):** `all_cows, 5, replace=False`

**Answer (ii):** `22`

**Answer (iii):** `n == 2`

**Answer (iv):** `count_event / repetitions`

- **Blank (i):** Each sighting takes $5$ cows from the town's $100$
  cows, so we draw $5$ elements from `all_cows`. Since the problem says
  5 **different** cows go missing, we must sample **without**
  replacement, hence `replace=False`.
- **Blank (ii):** `all_cows` is `np.arange(100)`, i.e. the numbers $0$
  through $99$. Lauren owns $23$ of them, and the natural way to label
  her cows is as the first $23$ numbers, $0$ through $22$. So a cow
  belongs to Lauren exactly when its number is less than or equal to
  $22$. The comparison `abducted <= 22` produces a Boolean array, and
  `np.count_nonzero` counts the `True` values, so `n` is the number of
  Lauren's cows that were abducted. Note that writing `23` here would
  incorrectly give Lauren $24$ cows.
- **Blank (iii):** We're estimating the probability that **exactly** two
  of Lauren's cows are taken, so the condition is `n == 2`. Writing
  `n >= 2` would answer a different question.
- **Blank (iv):** An empirical probability is the number of repetitions
  in which the event happened divided by the total number of
  repetitions.
