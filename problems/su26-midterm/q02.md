Define the variables `once` and `twice` as follows.

    once = ufo.groupby("zipcode").count()
    twice = once.groupby("shape").count()

# BEGIN SUBPROB

Determine the **value** resulting from the following expression. You may
indicate that the value cannot be determined or the expression produces
an error.

    ((once.get("duration") < 2) & (once.get("duration") >= 2)).sum()

# BEGIN SOLUTION

**Answer:** `0`

The two conditions being combined are exact opposites of one another: a
number cannot be both strictly less than $2$ and greater than or equal
to $2$ at the same time. Combining them with `&` therefore produces a
Series containing `False` in every position, no matter what's in `once`.

Summing a Boolean Series counts the number of `True` values, and since
there are none, the result is $0$. We don't need to know anything about
the contents of `ufo` to answer this.

# BEGIN SUBPROB

What can we conclude using **only** the `twice` DataFrame? **Select only
one of the options** and in no more than three sentences, explain your
answer.

( ) The zip codes where exactly 3 UFO sightings occurred.
( ) The number of sightings for each UFO shape where exactly 3 distinct zip codes were reported.
( ) The number of zip codes where exactly 3 distinct UFO shapes were reported.
( ) The number of zip codes where exactly 3 UFO sightings occurred.
( ) The number of sightings where the UFO shape was spherical.

# BEGIN SOLUTION

**Answer:** The number of zip codes where exactly 3 UFO sightings
occurred.

Work from the inside out. `once = ufo.groupby("zipcode").count()` has
one row per zip code, and every column of `once` holds the same number:
the count of sightings in that zip code. In particular, the `"shape"`
column of `once` is a *number of sightings*, not a shape.

So `twice = once.groupby("shape").count()` groups the zip codes by their
number of sightings. Its index is a number of sightings and each entry
counts how many zip codes had that many sightings. Looking up the row
labeled `3` in `twice` tells us the number of zip codes where exactly
$3$ sightings occurred.

Here is the code that inspired the other options:

- *The zip codes where exactly 3 UFO sightings occurred:*
  `ufo.groupby("zipcode").count()`
- *The number of sightings for each UFO shape where exactly 3 distinct
  zip codes were reported:* `ufo.groupby(["zipcode", "shape"]).count()`
- *The number of zip codes where exactly 3 distinct UFO shapes were
  reported:* `ufo.groupby(["zipcode", "shape"]).count()`
- *The number of sightings where the UFO shape was spherical:*
  `ufo.groupby("shape").count()`
