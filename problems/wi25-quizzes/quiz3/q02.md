# BEGIN PROB

The DataFrame `geisel` contains a row for each day of this academic
year. The `"Students"` column contains the number of students who
visited Geisel Library on that day, as an `int`.

# BEGIN SUBPROB

Fill in the blanks below such that

-   `geisel_sample` is a **simple random sample** of 50 rows of
    `geisel`, and

-   the code prints the endpoints of a 95% bootstrapped confidence
    interval for the **mean** number of students at Geisel Library,
    based on the data in `geisel_sample`.

```py
    geisel_sample = __(a)___
    y = np.array([]): 
    for i in np.arange(10000): 
        x = __(b)__
        y = np.append(y, x)
    print(np.percentile(y, 2.5), np.percentile(y, 97.5))

```

# BEGIN SOLUTION

**Answer (a):** `geisel.sample(50)` or `geisel.sample(50, replace = False)`

**Answer (b):** `geisel_sample.sample(50, replace = True).get("Students").mean()` or equivalent

For **blank (a)**, each row of `geisel` is one day. We need to perform a simple random sample 50 days, so sample 50 rows without replacement. 
For **blank (b)**, Since we are performing bootstrapping, we draw 50 times from those same 50 days *with replacement*, so a day can appear more than once in a resample. We record the mean of its `"Students"` counts, and then we are appending them to an array called `y`. We do this 10,000 times, so the array `y` will be filled with 10,000 resample means. The 2.5th and 97.5th percentiles of the 10,000 resample means give the endpoints of the 95% bootstrap interval.
