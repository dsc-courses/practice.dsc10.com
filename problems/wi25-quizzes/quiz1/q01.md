# BEGIN PROB

The Cheese Club currently has 50 members. Each quarter, the number of
people who will join the club is the value of the Python expression
below.

    3 * ((4 * 20 / 5 * 2 + 4) ** 0.5 - 2 ** 2)

How many members will the club have **after 3 quarters**?

( ) 56 
( ) 68 
( ) 74 
( ) 82 
( ) None of these.

# BEGIN SOLUTION

**Answer**: `68`

Work from the innermost parentheses out, following order of operations:

1. `4 * 20 / 5 * 2` runs left to right, since `*` and `/` have equal precedence: $80 / 5 = 16$, then $16 \cdot 2 = 32$.
2. `32 + 4 = 36`
3. `36 ** 0.5 = 6.0`. Raising to the 0.5 power is a square root.
4. `2 ** 2 = 4`, so the parentheses give $6.0 - 4 = 2.0$.
5. `3 * 2.0 = 6.0` new members per quarter.

After 3 quarters:

$$50 + 3 \cdot 6 = 68$$
