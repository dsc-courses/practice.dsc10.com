# BEGIN SUBPROB

One of the clubs in the `clubs` DataFrame is the `"Surf Club"`.
**Without** querying, write an expression that evaluates to the rating
of this club.

# BEGIN SOLUTION

**Answer**: `clubs.set_index("Name").get("Rating").loc["Surf Club"]`

Club names are unique, so we can make `"Name"` the index with `.set_index("Name")`. Then `.get("Rating")` pulls out the ratings as a Series, indexed by club name. `.loc["Surf Club"]` grabs the value whose index **label** is `"Surf Club"`. The order `.loc["Surf Club"].get("Rating")` also works, as long as `set_index` comes first.

# BEGIN SUBPROB

Now, using a query, write an expression that evaluates to the rating of
the `"Surf Club"`.

# BEGIN SOLUTION

**Answer**: `clubs[clubs.get("Name") == "Surf Club"].get("Rating").iloc[0]`

1. `clubs.get("Name") == "Surf Club"` makes a Boolean Series that's `True` only for the Surf Club row.
2. `clubs[...]` keeps just the rows where it's `True`. That's a DataFrame with one row.
3. `.get("Rating")` gives a Series with **one** value. It's still a Series, not a number.
4. `.iloc[0]` pulls out the value at position 0. We use `.iloc` (position) rather than `.loc` (label) because a query keeps the original index labels, so the Surf Club row's label isn't necessarily 0.

# BEGIN SUBPROB

Fill in the blanks so the expression below evaluates to the name of the
category (e.g. `"Social"`) with the largest number of members, on
average.

```py
(clubs.groupby(__(a)__).__(b)__.sort_values(by="Members", ascending=__(c)__).__(d)__)
```

# BEGIN SOLUTION

**Answer**: 

`(a)`: `"Category"`

`(b)`: `mean()`

`(c)`: `False`

`(d)`: `index[0]`

- **(a), (b):** We want the average members **per category**, so we group by `"Category"` and aggregate with `.mean()`.
- **(c):** Sorting by `"Members"` with `ascending=False` puts the category with the largest average at the top.
- **(d):** After a `groupby`, the category names become the **index**, not a column. So `.index[0]` gives the first label in the sorted index, which is the category name we want.

# BEGIN SUBPROB

In each category, what is the largest budget for a club? Write one line
of code that would produce an appropriate **data visualization** to
answer this question.

# BEGIN SOLUTION

**Answer**: `clubs.groupby("Category").max().plot(kind= "bar", y= "Budget")`

There are two steps:

1. **Get the right numbers.** `.groupby("Category").max()` finds the largest value of each column within each category. The `"Budget"` column of the result is the largest budget per category.
2. **Pick the right plot.** We're comparing one number across categories, so a **bar chart** fits (`kind="barh"` is also fine). `y="Budget"` says which column to plot. The category names are in the index, so they automatically label the bars.
