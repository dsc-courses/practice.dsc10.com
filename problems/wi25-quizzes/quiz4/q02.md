# BEGIN PROB

A researcher collects data on many flowers, some of which have been
treated with fertilizer and some of which have not (untreated). The
researcher wants to determine whether there is a relationship between
fertilizer use and the height of the flowers.

# BEGIN SUBPROB

Choose the correct formulation of the null and alternative hypotheses.

( ) **Null**: There is a difference in the average height of treated and untreated flowers.\ **Alt:** There is no difference in the average height of treated and untreated flowers.
( ) **Null:** There is no difference in the average height of treated and untreated flowers.\ **Alt**: There is a difference in the average height of treated and untreated flowers.\
( ) **Null**: There is no difference in the average height of treated and untreated flowers.\ **Alt:** Treated flowers grow taller,on average, than untreated flowers.
( ) **Null**: Fertilizer use has no impact on flower height.\ **Alt:** Fertilizer use causes taller flowers.

# BEGIN SOLUTION

**Answer:** B

**Explanation:**

- The null hypothesis has to be the "nothing interesting is happening" model, so option 1 is backwards.

- The researcher wants to know whether there is *a relationship* between fertilizer and height. No direction is given, so the alternative should be two-sided ("there is a difference"), not "treated flowers grow taller" (option 3).

- Option 4 talks about **causation**. This is observational data (the researcher only collects data and does not randomly assign fertilizer), so a hypothesis test can't show that fertilizer *causes* taller flowers.

# BEGIN SUBPROB

True or False: We could use a permutation test to test these hypotheses.

( ) True 
( ) False

# BEGIN SOLUTION

**Answer:** True

**Explanation:** The question is whether two samples (treated and untreated) come from the same population distribution. That is exactly what a permutation test checks. We shuffle the treated/untreated labels, recompute a statistic such as the absolute difference in group means each time, and compare the observed statistic to that simulated distribution.
