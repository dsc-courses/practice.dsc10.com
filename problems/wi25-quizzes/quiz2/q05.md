# BEGIN PROB

Fill in the body of the function `prep_time` such that both expressions
below evaluate to the same Series.

```py
    blue_bowl.get("num_toppings").apply(prep_time)

    1.2 + 0.2 * blue_bowl.get("num_toppings")

    def prep_time(x): 
        return 
```

# BEGIN SOLUTION

**Answer:** `1.2 + .2 * x`

`1.2 + 0.2 * x` is correct because .apply(prep_time) calls prep_time once for each value in the `num_toppings` Series and passes that number in as `x`. The second expression applies 1.2 + 0.2 × (number of toppings) to every element. So the function has to do that same math to a single number x.

`1.2 + 0.2 * blue_bowl.get("num_toppings")` is incorrect as the function body. It would return a whole Series for every input instead of one number. It also ignores `x`.
Using `print(...)` instead of return is incorrect. The function would return None, so the result would be a Series of None values.
