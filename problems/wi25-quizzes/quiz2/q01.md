# BEGIN PROB

Fill in the blanks so that the statement below outputs a DataFrame
showing the most popular base and fruit combinations in the `blue_bowl`
DataFrame, in descending order of popularity.

```py
    blue_bowl.groupby(__(a)__).__(b)__.sort_values(__(c)__)
```

# BEGIN SOLUTION

**Answer (a):** `['base', 'fruit']`

We want combinations of base and fruit. Grouping by a list of two columns makes one group for each unique (base, fruit) pair. Grouping by only `base` or only `fruit` would count each one separately.

<average>90</average>

**Answer (b):** `count()`

Popularity means how many orders had each combination. `.count()` gives the number of rows in each group. `.sum()` would add up num_toppings, and `.mean()` would average it. Neither one measures popularity.

<average>90</average>

**Answer (c):** `"student_id", ascending = False`

After using `.count()`, every remaining column holds the same number (the size of the group). So sorting by any of the columns work, but `student_id` is a safe choice. We need `ascending = False` to put the most popular combinations first. The default, ascending order, would put the least popular first.

<average>84</average>
