# BEGIN PROB

The DataFrame `mascots` has 10 rows, one for each UC school, and only
two columns, `"school"` and `"mascot"`. Assuming that the entries in the
`"school"` column are formatted exactly how they appear in the
`"Campus"` column of `uc`, how many rows does the following merged
DataFrame have?

    uc.merge(mascots, left_on="Campus", right_on="school")

( ) `10`
( ) `60`
( ) `70`
( ) `600`
( ) None of these.

# BEGIN SOLUTION

**Answer:** `60`

The `uc` DataFrame has 60 rows, with six rows for each of the 10 UC
campuses (one for each academic year). The `mascots` DataFrame has
exactly one row for each campus.

Since the merge matches each row in `uc` with the corresponding
single row in `mascots`, no rows are added or removed. Therefore,
the merged DataFrame has 60 rows.
