# BEGIN PROB

We plan to collect a sample of movies and use this sample to estimate
the proportion of all movies with the genre `"Musical"`, a population
parameter.

# BEGIN SUBPROB

If we want to create a $95\%$ confidence interval that is at most $0.08$
wide, which of the expressions below represents the smallest sample size
we should collect?

( ) $\left(\dfrac{1}{0.02}\right)^2$ 
( ) $\left(\dfrac{1}{0.04}\right)^2$ 
( ) $\left(\dfrac{1}{0.08}\right)^2$ 
( ) $\left(\dfrac{1}{0.16}\right)^2$

# BEGIN SOLUTION
**Answer**: $\left(\dfrac{1}{0.04}\right)^2$

The width of a 95% confidence interval for a population proportion is approximately

$$4 \cdot \frac{\text{sample SD}}{\sqrt{n}}$$

We don't know the sample SD before we collect the sample. But for a collection of 0s and 1s, the SD is $\sqrt{p(1-p)}$, which is never more than 0.5. Using 0.5 gives us the widest possible interval, so the width is at most

$$4 \cdot \frac{0.5}{\sqrt{n}} = \frac{2}{\sqrt{n}}$$

We want that to be at most 0.08:

$$\frac{2}{\sqrt{n}} \leq 0.08 \implies \sqrt{n} \geq \frac{2}{0.08} = \frac{1}{0.04} \implies n \geq \left(\frac{1}{0.04}\right)^2 = 625$$

# BEGIN SUBPROB

Let $W$ represent the maximum width of a $95\%$ confidence interval
obtained from a sample that is **twice as big** as the sample size you
found in part (a). Which of the following is true?

( ) $0 < W < 0.04$ 
( ) $W = 0.04$ 
( ) $0.04 < W < 0.08$ 
( ) $W \geq 0.08$

# BEGIN SOLUTION
**Answer**: $0.04 < W < 0.08$

The maximum width is $\frac{2}{\sqrt{n}}$. That means doubling $n$ divides the width by $\sqrt{2}$, not by 2:

$$W = \frac{2}{\sqrt{2 \cdot 625}} = \frac{0.08}{\sqrt{2}} \approx 0.057$$

A bigger sample gives a narrower interval, so $W < 0.08$. Because the width shrinks with $\sqrt{n}$, though, doubling the sample size doesn't cut the width in half, so $W > 0.04$. To get a width of 0.04 you'd need **four** times the sample size.
