What would be the best type of plot to visualize the distribution of
`"neighborhood"` among the houses represented in `treat`?

( ) scatter plot
( ) line plot
( ) bar chart
( ) histogram

# BEGIN SOLUTION

**Answer**: bar chart

`"neighborhood"` is a categorical variable consisting of different locations. To visualize its distribution, meaning the count of each `"neighborhood"`, we would use a bar chart.

Scatter plots and line plots both visualize the relationship between two quantitative variables, while a histogram visualizes the distribution of a single quantitative variable using bins.

Suppose we had access to historical data about the price of fun-sized
candies over time. If we wanted to compare the prices of Milky Way and
Skittles over time, which would be the best type of visualization to
plot?

( ) overlaid scatter plot
( ) overlaid line plot
( ) overlaid bar chart
( ) overlaid histogram

# BEGIN SOLUTION

**Answer**: overlaid line plot

Here, we're comparing the price of candy over time by year, which is a relationship between two quantitative variables. This gives us two options: a scatter plot or a line plot. An overlaid scatter plot would only mark individual points, whereas an overlaid line plot connects them, making it better suited for showing trends from year to year.
